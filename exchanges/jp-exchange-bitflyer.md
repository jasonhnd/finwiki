# 株式会社 bitFlyer — 日本暗号資産交換業者 overview

> FSA 登録番号 関東財務局 第00003号 · JVCEA 会員 #1002 · 登録日 2017-09-29

## 1. 法人・株主

- **商号**：株式会社 bitFlyer（英文: bitFlyer Inc.）
- **設立**：2014年1月9日
- **本店所在地**：〒107-6230 東京都港区赤坂9-7-1 ミッドタウン・タワー
- **資本金**：41億238万円（資本準備金含）（公式サイト掲載値、時点未指定）
- **親会社**：公式会社概要は株式会社 bitFlyer Holdings を株式会社 bitFlyer の株主・親会社として掲載し、Holdings の設立日を2018年10月1日、資本金を50億円（資本準備金含む）と開示している。^[Source: https://bitflyer.com/ja-jp/s/company.]
- **株主構成（Holdings 段階）**：bitFlyer の現行公式開示は Holdings 自体の private cap table を掲載していないため、2022年の報道推計（創業者・少数株主の比率）を 2026年の現行持分として再掲しない。確認できる範囲は、株式会社 bitFlyer の株主が bitFlyer Holdings であることと、両社の現行役員・資本金である。^[Sources: https://bitflyer.com/ja-jp/s/company; https://bitflyer.com/ja-jp/s/director-profile.]
- **会計監査人**：EY新日本有限責任監査法人
- **主要取引銀行**：三井住友銀行
- **法人番号**：2011101068824

## 2. 牌照・登録状況

- **暗号資産交換業**：関東財務局長 第00003号（登録日 2017-09-29）
- **金融商品取引業**：関東財務局長（金商）第3294号
- **JVCEA 会員**：第一種 #1002 — 暗号資産交換業・暗号資産デリバティブ取引 両方保有
- 電子決済手段等取引業・資金移動業の登録は非確認

## 3. 取扱通貨

取扱銘柄は追加・廃止され得るため、固定リストや固定数を本項へ転記せず、bitFlyer の現行取扱暗号資産ページを優先する。

**特色**：BTC/JPY の Lightning Spot と暗号資産デリバティブを提供する。過去の期間限定順位を現在の市場順位として扱わない。

## 4. 業務範囲

- **現物取引（販売所・取引所）**：あり（Lightning Spot）
- **デリバティブ（Lightning FX）**：あり（金融商品取引業として）
- **貸暗号資産（レンディング）**：不明（公式確認不可）
- **クレジットカード**：「bitFlyer クレカ」（アプラス発行、2021年12月開始。ビットコインが貯まるタイプ）
- **法定通貨入金チャネル**：銀行振込（三井住友銀行ほか）・クイック入金対応（公表済）
- **法人向けサービス**：「ビットコイン決済サービス」（丸井グループ・IDOMなど複数実績）
- **ポイント連携**：Tポイント・モッピー・PeX 等と連携歴あり

## 5. 市占・取引高

- 過去の特定期間について自社発表の取引量順位や顧客数があるが、現在の順位・口座数として転用しない。
- 直近の取引高・口座数について、各社を同一期間・同一定義で比較できる公式値は本項で確認していない。
- **競合ポジション**：市場順位を断定せず、[[exchanges/jp-exchange-coincheck|Coincheck]]、[[exchanges/jp-exchange-gmo-coin|GMOコイン]]、[[exchanges/jp-exchange-bitbank|bitbank]] などと現行の商品・公表統計を同じ基準で比較する。JVCEA 自主規制および会員制度については [[exchanges/jvcea-self-regulatory-overview|JVCEA 自主規制体系]] 参照。

## 7. 戦略動向

- **2024年 FTX Japan 買収**：bitFlyer Holdings は 2024年6月に株式取得契約を発表し、7月26日に全株式取得を完了、8月28日に Custodiem へ商号変更した。公式発表はデジタル資産 custody 事業の展開方針を記載する（[[exchanges/ftx-japan-100pct-return-case-study|FTX Japan 100% 返還ケーススタディ]] 参照）。
- **海外法人の現状**：bitFlyer USA, Inc.（デラウェア法人）および bitFlyer EUROPE S.A.（ルクセンブルク）の 2018年当時の海外展開は公表されているが、2026年5月時点の運営状況は公式確認不可。
- **本田翼 CM 起用**：2024年9月より本田翼を起用した広告展開（公式リリース 2024-08-28）。

## 8. 関連人物

- **加納 裕三**（かのう ゆうぞう）— 共同創業者・代表取締役。2014年創業から代表を務め、一時退任後 2023年3月に再就任。日本ブロックチェーン協会（JBA）の設立を主導した業界の顔的存在。
- **小宮山 峰史**（こみやま たかし）— 共同創業者。現行の役職・保有比率は公式会社概要で確認できないため、過去の報道値を現在値として扱わない。
- **平子 惠生**（ひらこ けいせい）— 2019年1月〜2020年3月 代表取締役。
- **三根 公博**（みね ともひろ）— 2020年3月〜2021年3月 代表取締役。
- **林 邦良**（はやし くによし）— 2021年3月〜2023年3月 代表取締役。
- **佐々木 亮太**（ささき りょうた）— Holdings 取締役（2024年時点）。
- **ジョエル・エジャトン（Joel Edgerton）** — Holdings 取締役（2024年時点）。
