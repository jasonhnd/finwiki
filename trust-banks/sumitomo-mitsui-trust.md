# 三井住友トラストグループ (SuMi TRUST)

## Wiki route

This entry sits under [[trust-banks/INDEX|trust-banks INDEX]]. Read it against [[trust-banks/master-trust-bank|日本マスタートラスト信託銀行]] for peer / contrast context and [[banking/INDEX|banking index]] for the broader system / regulatory boundary.

## TL;DR

メガバンクから独立した信託銀行中心の金融持株会社で、**3 大信託の一角**（三菱 UFJ 信託 / 三井住友信託 / みずほ信託）。2002-02 中央三井トラスト HD 設立 → 2011-04 住友信託銀行と統合 → 三井住友トラスト・ホールディングス発足 → **2024-10-01 三井住友トラストグループに商号変更**。年金・不動産・証券代行・遺言信託などを展開する。FY2025 の親会社株主帰属純利益は **3,175.66 億円**、2026-03 末総資産は **82.17 兆円**。**注意：[[megabanks/smfg]] (三井住友 FG) とは別法人** — 「三井住友」名称が共通だが、SuMi TRUST は旧三井・住友の信託系統、SMFG は銀行系統で、別の企業グループである。^[三井住友トラストグループ「2026年3月期決算短信」: https://www.smtg.jp/-/media/tg/investors/fs/2603/2603_01.pdf]

### 合併歴史・前身

- **旧 三井信託銀行**：1924 設立（旧三井財閥系信託、日本初の信託会社系列のひとつ）
- **旧 住友信託銀行**：1925 設立（旧住友財閥系信託）
- **旧 中央信託銀行**：戦後設立、後に三井信託と合併
- **中央三井信託銀行**：2000 三井信託銀行 + 中央信託銀行 合併
- **中央三井トラスト HD**：2002-02 設立（中央三井信託 + 中央三井アセット信託の持株会社）
- **三井住友トラスト HD**：2011-04 中央三井トラスト HD + 住友信託銀行 統合

> **統合背景**：住友信託銀行は単独路線を志向していたが、リーマンショック後の業界再編圧力と信託専業独立維持の戦略一致から、2009 年に中央三井トラスト HD との経営統合方針を発表。2011-04 株式交換方式で統合、信託専業 FG として最大規模を確立。^[likely]

### 信託専業独立路線

- **メガから独立**：3 大信託のうち、三菱 UFJ 信託は [[megabanks/mufg]] 傘下、みずほ信託は [[megabanks/mizuho-fg]] 傘下。**SuMi TRUST のみメガから独立した持株会社で、信託専業**。これがアイデンティティかつ差別化軸。
- **「三井住友」名称の混同リスク**：[[megabanks/smfg]]（三井住友 FG = SMBC 系）と名称が共通だが、別法人・別資本。SMFG は旧太陽神戸銀行 + 旧住友銀行系の銀行系列、SuMi TRUST は旧三井信託 + 旧住友信託の信託系列。

### 富裕層・法人運用シフト

- **個人富裕層**：遺言信託・資産承継・相続対策で旧三井家・旧住友家以来の顧客基盤を活用
- **法人**：年金資産受託（DB / DC）・不動産信託・証券代行で大企業顧客基盤
- **機関投資家**：アモーヴァ・アセットマネジメント + 三井住友トラスト AM で投信運用を 2 ブランド体制

### 提携・買収戦略

- **SBI HD との合弁会社** ([[regional-banks/ssnb]] / 住信SBIネット銀行)：ネット銀行領域の主要チャネル。持分比率は基準日付きの最新開示で確認する。
- **パナソニックとの JV**（三井住友トラスト・パナソニックファイナンス）：リース・ファイナンス
- **旧日興アセットマネジメント取得**（2009 シティから段階的、現アモーヴァ・アセットマネジメント）：投信運用領域強化

### 中期経営計画「Trust 2030」（2024）

- 信託機能を軸に、年金・不動産・資産承継・サステナビリティ関連受託の拡大
- BaaS 領域は SBI 住信ネット銀行経由で間接展開 ^[likely]

## 4. 規制・政策

- **主管**：金融庁（FSA）
- **持株会社規制**：銀行法 第 52 条の 17（信託銀行の持株会社にも準用）
- **信託業法**：信託銀行業務全般
- **G-SIB**：MUFG と異なり G-SIB 指定なし（規模・グローバル連関性が相対的に小さい）^[likely]
- **直近政策論点**：
  - 2024〜 日銀政策金利正常化 → 信託報酬・運用利回り環境の変化
  - 2025〜 BaaS / ネット銀行領域での 住信 SBI ネット銀行（[[regional-banks/ssnb]]）の動向
  - 2025〜2026 資産承継・相続関連サービスの規制環境変化
