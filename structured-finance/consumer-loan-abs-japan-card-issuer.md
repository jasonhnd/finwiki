# Consumer-loan and card-receivable ABS in Japan — evidence guide

## TL;DR

The prior page presented a “main repeat issuer” list and generalized vehicle, revolving, trigger, enhancement, rating and investor mechanics without named public transactions. Those claims are removed. Consumer cash loans, shopping credit, card receivables and auto installment receivables are distinct assets and must not be merged by issuer brand.

## 1. Issuer and asset identity

[JSDA's securitization-market survey](https://www.jsda.or.jp/en/statistics/securitization-market/) is a public entry point; the following table states the named-deal evidence required.

| Field | Required public evidence |
|---|---|
| Legal issuer / trust | Offering or rating document |
| Originator / servicer | Transaction documents |
| Current parent | Dated corporate disclosure |
| Receivable type | Eligibility criteria and cutoff pool |
| Repeat issuance | Dated series history with a defined period |
| Vehicle | Trust / SPV legal documents |

## 2. Legal and pool boundary

[The Interest Rate Restriction Act](https://laws.e-gov.go.jp/law/329AC0000000100) and [Installment Sales Act](https://laws.e-gov.go.jp/law/336AC0000000159) support legal categories, while the following pool facts remain transaction-specific.

| Question | Required evidence |
|---|---|
| Which statute applies? | Receivable contract and product type |
| What is the APR / fee? | Pool disclosure, not the statutory maximum alone |
| Is the pool revolving? | Replenishment terms |
| What triggers amortization? | Exact transaction metric and threshold |
| What enhancement exists? | Actual classes, reserve, OC and support |
| What is the rating? | Dated class-specific agency action |

## 3. Performance and distribution

[JCR's general methodology](https://www.jcr.co.jp/en/pdf/dm28/General_Methodology20210802.pdf) supports the following evidence checklist.

| Claim | Required evidence |
|---|---|
| Delinquency / default / recovery | Definitions, period and pool report |
| Waterfall | Named priority of payments |
| Trigger status | Dated trustee / servicer report |
| Retention | Actual holder and amount |
| Investor / distributor | Public allocation or transaction disclosure |
| Spread | Named pricing result and benchmark |

## 4. Deferred claims

Issuer ranking, “main repeat” status, standard vehicle, revolving period, trigger level, enhancement, rating combination and investor base remain deferred without a public named transaction.
