# Japan private RMBS issuance structure — named-deal evidence guide

## TL;DR

The prior page generalized private-RMBS originators, trust preference, tranche counts, enhancement, ratings, spreads and investors. Those claims are removed. Private RMBS terms are deal-specific. JHF MBS is separately documented: JHF owes timely payment before a beneficiary-interest event; the structure is not a conventional senior/subordinated stack or a separate JHF guarantee.

## 1. Named private RMBS

[JSDA's securitization-market survey](https://www.jsda.or.jp/en/statistics/securitization-market/) and [JCR's rating list](https://jcr.co.jp/en/ratinglist/sf_sf/) are entry points; the following table states the full evidence required.

| Field | Required public evidence |
|---|---|
| Legal issuer / trust | Offering, trust or rating document |
| Originator / servicer | Sale and servicing documents |
| Mortgage pool | Eligibility, cutoff and stratification |
| Vehicle / transfer | Trust / SPV and perfection documents |
| Classes / enhancement | Closing balances, waterfall, reserve and support |
| Rating / pricing | Dated class action and named issue result |

## 2. JHF comparison

[JHF's official FAQ](https://www.jhf.go.jp/english/mbs_faq.html) supports the JHF column; the private column remains named-deal specific.

| Dimension | JHF MBS | Private RMBS |
|---|---|---|
| Issuer / obligor | JHF; timely-payment obligation before a beneficiary-interest event | Named trust / SPV / obligor |
| Trust mechanism | Third-party beneficiary trust; certificates replace bonds after an event | Deal-specific |
| Credit enhancement | Ordinary monthly MBS use OC for post-event certificates; Green MBS do not | Deal-specific |
| Collateral | Eligible Flat 35 mortgages purchased by JHF | Named pool |
| Rating | Dated JHF series rating | Dated class rating |
| Pricing | Dated JHF result | Dated named transaction; no generic band |

## 3. Pool, waterfall and performance

[JCR's methodology library](https://www.jcr.co.jp/en/rrinfo/meth_sf/) supports the following analytical checklist.

| Field | Required named-deal evidence |
|---|---|
| Loan attributes | LTV, rate type, term, seasoning and geography as disclosed |
| Default / recovery | Definitions, assumptions, costs and timing |
| Prepayment | Pool data and cited scenarios |
| Waterfall | Class priority, triggers and loss allocation |
| Counterparties | Servicer, account, trustee and hedge terms |
| Performance | Dated trustee / servicer or rating disclosure |

## 4. Deferred claims

Originator ranking, standard trust use, 3–4-class structures, AAA/AA outcomes, subordination ranges, investor base and 50–100bp spread remain deferred without a named public transaction.
