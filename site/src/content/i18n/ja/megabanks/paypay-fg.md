# PayPay 金融エコシステム（分析上のグループ呼称）

## TL;DR

「PayPay 金融グループ」は本項が決済・カード・銀行・証券の連携を読むために使う**分析上の呼称**であり、同名の法定持株会社を意味しない。中核の PayPay Corporation は 2026-03-12 に Nasdaq Global Select Market へ `PAYP` として上場した。上場後も SoftBank とそのグループ会社は議決権の 62.2%（経済持分 40.8%）を持ち、PayPay は SoftBank の連結子会社である。SoftBank の FY2025 Financial segment は売上高 4,045 億円、segment income 863 億円を計上した。PayPay は 2026-07 時点で登録ユーザー 7,400 万人を開示している。^[PayPay IPO: https://about.paypay.ne.jp/en/pr/20260312/01/; SoftBank FY2025 results pp. 14-15: https://www.softbank.jp/en/corp/set/data/ir/documents/presentations/fy2025/investors/pdf/sbkk_investors_presentation_20260511_en.pdf; PayPay users: https://about.paypay.ne.jp/en/pr/20260702/01/]

## 1. 呼称と法的境界

- **法的主体**：PayPay Corporation
- **設立**：2018-06-15
- **事業**：モバイル決済を含む電子決済サービスの開発・提供
- **本社**：YOTSUYA TOWER（東京都新宿区四谷 1-6-1）
- **登記上の所在地**：東京都千代田区紀尾井町 1-3
- **上場市場 / ticker**：Nasdaq Global Select Market / `PAYP`（2026-03-12）

設立日とサービス開始日を混同してはいけない。PayPay の公式会社概要は設立日を **2018-06-15** としており、旧版にあった「2018-10-05 設立」は決済サービス開始時期との混同だった。([PayPay company profile](https://about.paypay.ne.jp/en/about/))

PayPay の公式会社概要は PayPay Card、PayPay Bank、PayPay Securities、PayPay SC、PayPay India、Credit Engine を group companies として掲げる。一方、SoftBank の segment disclosure は SoftBank 連結ベースの議決権比率を開示する。両者は同じ意味の「資本ツリー」ではないため、以下では分けて表示する。

## 2. SoftBank Financial segment の主要主体

| 主体 | SoftBank 開示の議決権比率 | 主な機能 | 開示上の注意 |
|---|---:|---|---|
| PayPay Corporation | 62.2% | モバイル決済等 | Nasdaq 上場後も SoftBank 連結子会社 |
| PayPay Card Corporation | 100.0% | クレジットカード、カードローン、信用保証 | Financial segment |
| PayPay Bank Corporation | 75.5% | 銀行 | FY2025 Q1 から Media & EC ではなく Financial segment |
| PayPay Securities Corporation | 75.3% | スマートフォン特化証券 | Financial segment |
| SB Payment Service Corp. | 100.0% | 決済代行 | PayPay 公式 group-company list とは別の Financial segment 主体 |

比率は SoftBank の 2026-03 期開示に基づく **SoftBank 側の連結議決権比率**であり、「PayPay Corporation が各社をこの比率で直接保有する」という意味ではない。([SoftBank, FY2025 results, p. 67](https://www.softbank.jp/en/corp/set/data/ir/documents/presentations/fy2025/investors/pdf/sbkk_investors_presentation_20260511_en.pdf))

## 3. 最新 KPI

| 指標 | FY2025 / 最新値 | 定義・時点 |
|---|---:|---|
| PayPay 登録ユーザー | 7,336 万人 | 2026-03-31、PayPay 単体 |
| PayPay 登録ユーザー | 7,400 万人 | 2026-07-02 発表時点 |
| 本人確認済ユーザー | 4,000 万人 | 2026-03-18、登録 7,300 万人中 |
| PayPay 単体の決済回数 | 92.434 億回 | FY2025 |
| PayPay consolidated GMV | 19.4 兆円 | FY2025、PayPay / Card / Bank の対象決済を内部取引消去後に集計 |
| SoftBank Financial segment 売上高 | 4,045 億円 | FY2025 |
| SoftBank Financial segment income | 863 億円 | FY2025 |

GMV と決済回数は同じ連結範囲ではない。SoftBank の data sheet は、GMV を PayPay Corporation、PayPay Card、PayPay Bank の対象決済を含む連結指標、決済回数を PayPay 単体指標として定義している。したがって両者を割って単純な「平均決済単価」を作ることはできない。([SoftBank FY2025 earnings data sheet, pp. 15, 19](https://www.softbank.jp/corp/set/data/ir/documents/presentations/fy2025/results/pdf/sbkk_earnings_datasheet_pdf_20260511.pdf); [PayPay, 2026-03-18](https://about.paypay.ne.jp/en/pr/20260318/02/))

## 4. 2026 IPO

PayPay は 2026-03-11（米国時間）に ADS 1 株当たり 16 ドルで IPO pricing を発表し、翌 3 月 12 日に Nasdaq で取引開始予定とした。募集は計 54,987,214 ADS で、PayPay の新規発行分と SVF II Piranha (DE) LLC の売出分から構成された。SoftBank は期末資料で上場完了と、上場後も PayPay を連結子会社として維持していることを確認した。したがって旧版の「IPO 観測」「上場準備」という記述は現状に合わない。^[PayPay IPO pricing: https://about.paypay.ne.jp/en/pr/20260312/01/; SoftBank FY2025 results p. 15: https://www.softbank.jp/en/corp/set/data/ir/documents/presentations/fy2025/investors/pdf/sbkk_investors_presentation_20260511_en.pdf]

## 5. LINE Pay 終了と LINE / PayPay 連携

LINE Pay の日本国内サービスは 2025-04-30 に終了した。これは PayPay への事業譲渡ではなく、利用者が一定期間に対象の LINE Pay 残高を PayPay 残高へ移す選択肢を伴う終了だった。LINEポイントは終了対象ではなく継続された。([LY Corporation, 2024-06-13](https://www.lycorp.co.jp/en/news/release/008632/))

2026-07-02、LINE Yahoo と PayPay は LINE と PayPay の account linking を発表した。PayPay 決済、送金・受取、LINEポイントと PayPayポイントの相互交換などを機能ごとに順次展開する計画であり、全機能が 2025 年に統合済みだったわけではない。([PayPay, 2026-07-02](https://about.paypay.ne.jp/en/pr/20260702/01/))

## 6. 機能マップ

| レイヤー | 主体 | エコシステム上の役割 |
|---|---|---|
| ウォレット / 決済 | [[payment-firms/paypay|PayPay]] | 高頻度の決済接点、本人確認、送金・受取 |
| カード | [[card-issuers/paypay-card|PayPay Card]] | クレジット決済と PayPay アプリ内の後払い導線 |
| 銀行 | PayPay Bank | 預金、口座接続、PayPay Debit 等 |
| 証券 | [[securities-firms/paypay-securities|PayPay Securities]] | 少額投資とアプリ内投資導線 |
| メディア / 通信接点 | LY Corporation / SoftBank | LINE、Yahoo! JAPAN、通信契約からの顧客接点 |

これはサービス導線の分析図であり、単一持株会社の法的組織図ではない。各金融商品には銀行法、金融商品取引法、割賦販売法、資金決済法等に基づく別々の主体・免許・顧客保護境界がある。

## 7. 開示を読む際の注意

- **登録ユーザーと active user を区別**：登録数、本人確認済数、monthly transaction users は別指標。
- **PayPay 単体と PayPay consolidated を区別**：決済回数と GMV の集計範囲は一致しない。
- **SoftBank segment と PayPay 法人を区別**：Financial segment には SB Payment Service なども含む。
- **議決権と経済持分を区別**：PayPay IPO 後の SoftBank group は議決権 62.2%、経済持分 40.8%。
- **決済シェアは同一定義で比較**：本項は、一次資料で定義を固定できない「QR 決済シェア約 2/3」を KPI として採用しない。
