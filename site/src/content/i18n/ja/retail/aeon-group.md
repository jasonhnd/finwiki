# AEONグループ リテール・ファイナンス運営マップ

## スコープ

AEONは、カード、銀行、保険販売、モバイル決済、電子マネーにまたがる統合型金融サービス事業を持つ小売グループである。本ページは、公表資料で確認できる事業体と商品レイヤーを整理する。すべてのAEONブランドのサービスを同一の法人が運営している、または適切な通知と法的根拠なしに小売データをグループ内で移転できるとは仮定しない。

## 公表資料で確認できるグループ構造

この表の情報源：AEONの[group-business directory](https://www.aeon.info/company/group/)、[AEON Financial Service overview](https://www.aeonfinancial.co.jp/en/corp/about/)、および[AEON Bank company outline](https://www.aeonbank.co.jp/sp/company/about/outline/)。

| レイヤー | 公表資料上の役割 | 証拠の限界 |
|---|---|---|
| イオン株式会社 | 小売、ディベロッパー、金融、サービスその他の事業を管理する純粋持株会社 | グループ親会社であることだけでは、金融商品の契約主体は特定できない |
| イオンフィナンシャルサービス株式会社 | イオングループの金融サービス事業を担う上場会社 | 単なる受動的な銀行持株会社ではなく、事業会社である |
| 株式会社イオン銀行 | 2006年設立、2007年にリテール銀行として開業した免許銀行 | 預金、融資、ATM、投資商品などの機能は銀行業の許可範囲に属する |
| イオン保険サービス株式会社 | 主にイオンのショッピングセンターで店舗を運営する保険代理店 | 代理店による販売と保険の引受は別である |
| イオンカード | 金融サービス事業におけるクレジットカードの商品群 | 発行会社と条件は、該当するカード契約で確認する必要がある |
| WAON / WAON POINT / AEON Pay | イオンの小売チャネルで利用される決済・ロイヤルティの各レイヤー | 電子マネー、ポイント、アプリ決済では、契約上・規制上の扱いが異なる |

イオンフィナンシャルサービスは、小売を起点とし、日本とアジアのほか10カ国・地域で事業を展開する総合金融グループだと説明している。地理的に展開しているだけで、各市場の商品や許認可が同一であるとは限らない。

## 小売から金融への流通

イオンの公式事業ページには、ショッピングセンター内の銀行支店と保険ショップ、グループ特典と結び付いたカード、イオンその他の場所に設置されたATM、買い物時に使える決済商品が記載されている。

この表の情報源：[AEON Financial Service domestic operations](https://www.aeonfinancial.co.jp/en/corp/enterprise/) および [AEON Financial Service corporate overview](https://www.aeonfinancial.co.jp/en/corp/about/)。

| 小売の顧客接点 | イオンが公表している金融機能 | 確認事項 |
|---|---|---|
| ショッピングセンター内の支店 | 預金、融資、資産運用相談その他の銀行サービス | 顧客の契約相手はイオン銀行か、それとも銀行代理業者か？ |
| 保険ショップ | 代理店を通じた保険の募集と比較 | 選択した保険を引き受ける保険会社はどこか？ |
| グループ店舗でのイオンカード | 決済と店舗固有の特典 | 対象商品、店舗、期間、除外条件は何か？ |
| イオン銀行ATM | 現金取引、提携カードの利用、WAONへのチャージ | 利用するカードの手数料と取扱時間はどう定められているか？ |
| WAON / AEON Pay | 加盟店での前払式またはアプリによる決済 | 価値の発行主体はどこで、返金や有効期限にはどの規約が適用されるか？ |

公表資料から確認できる流通上の強みは、日常の買い物の場で顧客と接点を持てることである。顧客獲得コストの低さ、与信成果の優位性、商品のクロスセル転換率を主張するには、日付のある経営開示または実測データが別途必要である。

## 権限マップ

イオンフィナンシャルサービスは、会社概要で、銀行代理業、クレジットカード番号等取扱契約締結事業者、第三者型前払式支払手段、電子決済等代行業などの許可・登録を公表している。

この表の情報源：[AEON Financial Service permissions and registrations](https://www.aeonfinancial.co.jp/en/corp/about/) および [AEON Bank's company information](https://www.aeonbank.co.jp/company/)。

| 活動 | 公表資料で特定できる法的主体 | 境界 |
|---|---|---|
| 預金・銀行融資 | イオン銀行 | 小売会社の一般的な会社権限だけで銀行商品を提供できるわけではない |
| 銀行仲介 | イオン銀行の銀行代理業者としてのイオンフィナンシャルサービス | 銀行代理業の許可は独立した銀行免許ではない |
| クレジットカード事業 | 該当するカード発行会社と登録済みのカード番号取扱事業者 | 商品契約によって発行会社とカード条件を特定する |
| 第三者型前払式支払手段 | 登録済みの前払式支払手段発行者 | 保全・払戻しの規則は銀行預金と異なる |
| 保険販売 | 保険代理店 | 保険契約のリスクは引受保険会社が負う |
| 海外の消費者金融 | 現地子会社と現地の許認可 | 日本の登録がアジア各国に自動的に通用するわけではない |

## イオンの事例から確認できること

- 小売店舗やショッピングセンターは、規制対象の金融サービスを継続的に提供する拠点になり得る。
- カード、銀行、前払式支払手段、ロイヤルティ、保険、アプリ決済は、同一グループブランドで示されても法的には別々の機能である。
- イオン銀行の支店・商品設計はショッピングセンターの顧客接点と結び付き、イオンフィナンシャルサービスは日本国外でも現地法人を通じて事業を行う。
- セブン銀行やローソン銀行と比較する際は、小売に根差したフルサービス銀行モデルとATMプラットフォーム型モデルを区別する必要がある。
