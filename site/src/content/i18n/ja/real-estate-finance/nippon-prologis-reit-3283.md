# Nippon Prologis REIT (3283)

## TL;DR

**Nippon Prologis REIT, Inc.（NPR、東証 J-REIT 3283）** は、米国に本社を置く **Prologis, Inc.**（NYSE: PLD）に関連する **プロロジス系列の先進型物流 J-REIT** である。GLP J-REIT の直後の 2013 年 2 月に上場し、NPR は正式なスポンサーサポートの枠組みを開示している。Prologis の現在の世界規模と日本での順位は、日付と定義を揃えたデータで測定する必要がある。NPR の正確な権利、保有および承認手続は、市場全体の雛形とせず、現行文書から確認する。

NPR のポートフォリオは、**首都圏、大阪、愛知 / 名古屋の物流サブマーケット** にある先進型物流施設に集中している。NPR または Prologis が施設クラスの呼称を使う場合は、独立した信用格付けではなく発行体定義の物件仕様として扱い、特徴を物件ごとに確認する。[[real-estate-finance/glp-j-reit-3281|GLP J-REIT]] との比較には、固定的な競争順位や共通のテナント層を仮定せず、同一時点のポートフォリオ、テナント、保有および売買データを使う。

## 3. Sponsor support agreement structure

NPR は Prologis との正式なスポンサーサポート契約を開示している。その内容は市場横断の開示順位ではなく、現行の条件、範囲および取引履歴から確認する：

表の根拠（2026-07-29 確認）：[日本プロロジスリートのスポンサーサポート開示](https://www.prologis-reit.co.jp/en/)。権利と承認手続は現在の公開資料から要約し、「通常」を開示比率の代用にしない。

| Component | Description |
|---|---|
| Preferential negotiation right | NPR は、日本で安定化したプロロジス開発物件の取得交渉に関する優先権を有する |
| Information rights | NPR はスポンサーのパイプライン開発進捗に関する情報を受領する |
| Warehousing support | スポンサーは、NPR の取得タイミングを待つ間、安定化資産を一時保有（ウェアハウジング）できる |
| Asset rotation cooperation | スポンサーは NPR のポートフォリオ刷新戦略に協力する |
| Sponsor unit-holder stake | プロロジスは開示された投資主持分を保有；現在の比率は最新の投資主開示で確認 |
| AM-company cooperation | 資産運用会社（Prologis REIT Management K.K.）はプロロジス・ジャパンによって人員を配置・支援される |
| Related-party-transaction governance | NPR の現行関連当事者方針と、各取引の鑑定、承認および開示記録を確認する |

この表は NPR のみを記述する。他の J-REIT が類似する名称を使っても、契約上の権利やガバナンスが同一であることにはならない。

## 7. 先進物流セグメントのスポンサーミックス

日本の先進型物流 J-REIT セグメントには、国境をまたぐスポンサー関係と国内スポンサー関係の双方がある。Prologis は NPR のスポンサーであり、GLP 投資法人は現在、より広い Ares スポンサーグループ内の GLP Japan を示している。他の上場ビークルには LaSalle、KKR 関連、三井不動産、三菱地所などとの関係がある。本ページは資産額または時価総額によるスポンサー支配を示すものではない。

表の根拠（2026-07-29 確認）：[日本プロロジスリート](https://www.prologis-reit.co.jp/en/)、[GLP J-REIT](https://www.glpjreit.com/en/)、[JPX 上場 REIT 一覧](https://www.jpx.co.jp/english/equities/products/reits/issues/index.html)。これらは発行体とスポンサー関係を示すが、それだけで従来セクター成長に結び付けられてきた因果説明を証明しない。

| 確認項目 | 必要な証拠 |
|---|---|
| スポンサーマップ | 比較対象の全ビークルについて最新の発行体・資産運用会社開示 |
| 規模 | 同一時点の取得価額、鑑定価額または時価総額を一つの定義で比較 |
| 開発寄与 | スポンサー資産と第三者資産を分けた物件別の出所・取得履歴 |
| 資本源 | 開示されたスポンサー、ファンドおよび発行体の資金調達。本拠地から速度や優位性を推定しない |
| テナント関係 | 日付付きテナント・リーシング開示。テナントの国籍から選好を推定しない |
