# 日本不動産への外国投資の税務上の取扱い

## 要約

外国投資家による日本不動産投資の税務は、納税者区分、直接保有かビークル経由か、所得・支払の種類、PE と実質的受益者の事実、国内源泉ルール、正確な租税条約本文、届出手続で異なる。賃料と譲渡対価には異なる源泉徴収制度があり、TK 配分、TMK／J-REIT の配当損金算入、証券譲渡益にはそれぞれ別の条件がある。以下の表は実取引の税率・免税を示さない。現行の国税庁ルール／手続と財務省の正確な条約本文を、資格ある日本税務専門家と確認するためのルートである。

## 税務面のマップ

表の出典注記：各行は別個の論点である。国税庁は非居住者の賃料と個人居住用例外、土地等の譲渡対価の源泉徴収を個別に扱う。条約軽減は正確な条約と手続を要し、別の行の税率・閾値・免税を転用しない。^[出典: https://www.nta.go.jp/english/taxes/individual/12014.htm, https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2879.htm, https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2888.htm, および https://www.mof.go.jp/english/policy/tax_policy/tax_conventions/tax_convetion_list_en.html.]

| 所得／事象 | 非居住者投資家の確認事項 |
|---|---|
| 賃料所得（直接保有） | 国内源泉、申告、源泉徴収。支払者と個人居住用の事実を確認 |
| 土地・建物の直接売却 | 譲渡益／国内源泉／申告と、非居住者への譲渡対価の買主側源泉徴収を別々に確認 |
| 日本の不動産関連法人株式 | 現行の資産・所有・保有・取引要件と正確な条約を確認 |
| J-REIT 分配 | 国内分類・源泉徴収、実質的受益者、条約、届出を確認 |
| J-REIT 投資口の売却 | 国内源泉、保有・取引、条約を確認。一般的なポートフォリオ免税を仮定しない |
| TK 損益配分／支払 | 営業者・投資家区分、配分時期、源泉、PE、条約を確認 |
| GK-TK／TMK の支払 | 先に法的な支払性質を特定し、ビークル名からパススルーを推定しない |
| クロスボーダーのブリッジ／メザニン・リターン | 利息、利益配分、分配、報酬その他を分類してから源泉・条約を適用 |

## 投資家タイプの区別

表の出典注記：法人、個人、年金、ソブリン、ビークルという名称は出発点であり条約結論ではない。居住、透明性、実質的受益者、PE 帰属、LOB／特典、届出証拠を正確な現行条約と日本法で確認する。^[出典: https://www.mof.go.jp/english/policy/tax_policy/tax_conventions/tax_convetion_list_en.html および https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2888.htm.]

| 投資家タイプ | 確認事項 |
|---|---|
| 非居住者法人（日本 PE なし） | 制限納税義務、国内源泉、条約を確認 |
| 非居住者法人（日本 PE／支店あり） | PE 帰属所得、国内法、条約を確認 |
| 非居住者個人 | 制限納税義務、賃料・譲渡申告、条約を確認 |
| 外国年金基金 | 一般免税なし。事業体、居住、実質的受益者、正確な条約規定・手続を確認 |
| 外国ソブリン関連投資家 | 一般的な主権免除を仮定せず、日本法、事業体、条約その他の適用文書を確認 |
| 外国籍投資ビークル | 日本の事業体分類と条約上の透明性・特典は事実関係固有 |

PE の有無と所得帰属は確認事項の一部であり、実際の事実なしに納税者、源泉、支払、所有、濫用防止、条約適格性、手続より上位のゲートとは扱わない。

## 恒久的施設（PE）のロジック

表の出典注記：論点整理のみである。国内法・条約の PE 定義、期間、代理、帰属、例外は異なるため、旧版の普遍的な 12 カ月基準を用いない。^[出典: https://www.mof.go.jp/english/policy/tax_policy/tax_conventions/tax_convetion_list_en.html.]

| PE パターン | 確認事項 |
|---|---|
| 日本支店 | 支店 PE と帰属所得を確認 |
| 建設／据付プロジェクト | 国内法と適用条約の期間その他の要件を確認。普遍的 12 カ月基準なし |
| 日本の代理人 | 契約締結・主要な役割・独立性等を現行ルールで確認 |
| 資産運用／PM 活動 | 人員、権限、意思決定、活動場所、委託先、帰属を確認。信託銀行の利用だけで PE 不存在を推定しない |

信託銀行またはアセットマネージャーの関与を標準的な軽減策またはセーフハーバーとは扱わない。[[trust-banks/mitsubishi-ufj-trust-bank]]と[[trust-banks/sumitomo-mitsui-trust]]は能力の文脈に限り、実際の機能、権限、活動場所、契約を確認する。

## 賃料所得への源泉徴収税

表の出典注記：国税庁は非居住者賃料のルールと個人居住用例外を具体的に示す。代理人・PM の行は契約と法定支払者の確認事項であり、別税率ではない。^[出典: https://www.nta.go.jp/english/taxes/individual/12014.htm.]

| 支払者／受取者 | 源泉徴収の確認 |
|---|---|
| テナントから非居住者賃貸人 | 国税庁は賃料の 20.42% 源泉を示すが、個人が自己・親族居住用に借りる例外を含め、現行法と事実を確認 |
| 日本居住代理人経由 | 代理の存在だけで法定支払者・源泉義務者は決まらない。支払と契約を追跡 |
| PM から非居住者へ送金 | 実際の取決めで支払者／源泉義務者か確認 |
| 条約手続 | 賃料軽減を仮定せず、正確な条約と必要な届出・書類を確認 |

納税者、所得、源泉徴収、条約上の地位、現行の国税庁手続によって、日本の法人税または所得税の申告が必要となる場合、あるいは申告できる場合がある。源泉税の控除または還付の可否は、適用される申告・課税手続に即して判断する。

## 非居住者のキャピタルゲイン

表の出典注記：国税庁 2878・1932 は非居住者個人による日本不動産直接売却の国内源泉・申告を示す。国税庁の非居住者／外国法人向け不動産資料は一定の「不動産関連法人」株式も対象になり得ると示すが、現行の事業体、資産、所有、保有、取引、納税者、条約要件を適用する。本表は一般的な閾値、免税、間接売却ルック・スルーを示さない。^[出典: https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2878.htm, https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1932.htm, https://www.nta.go.jp/about/organization/sapporo/hikyoju_gaikoku/pdf/01.pdf, および https://www.mof.go.jp/english/policy/tax_policy/tax_conventions/tax_convetion_list_en.html.]

| 売却類型 | 確認事項 |
|---|---|
| 日本不動産の直接売却 | 国税庁が扱う非居住者個人例では国内源泉で原則申告。譲渡対価の買主源泉は別制度で、条約効果は本文を確認 |
| 日本の不動産関連法人株式 | 一定の株式譲渡は日本の源泉ルール対象になり得る。一般的割合を置かず現行要件と条約を適用 |
| J-REIT 投資口 | 国内源泉、所有・取引、正確な条約を確認。一般的ポートフォリオ免税なし |
| TMK 優先出資 | 証券を分類し、国内源泉、納税者、所有・取引、条約を確認。TMK 名称から結論しない |
| 外国持株ビークル経由 | 実際の売主、資産／事業体チェーン、国内源泉、適用される濫用防止、条約を確認。一般的ルック・スルー結論なし |

不動産関連法人ルールは、納税者、資産、所有、保有、取引、国内源泉、正確な条約と並ぶ出口計画上の一論点であり、単一の最重要ゲートとは扱わない。

## TK 投資家の税務確認

商法 535 条以下が匿名組合（TK）を定義する。TK は候補となり得る契約経路の一つであり、名称から普及度、投資家層、税務結果を推定しない。

表の出典注記：商法 535 条以下が TK 契約を定義し、国税庁は個人 TK 分配と法人営業者／投資家の配分を別々に扱う。普遍的パススルーや no-PE セーフハーバーではない。^[出典: https://elaws.e-gov.go.jp/document?lawid=132AC0000000048, https://www.nta.go.jp/law/tsutatsu/kihon/shotoku/05/16.htm, および https://www.nta.go.jp/law/tsutatsu/kihon/hojin/14/14_01_01.htm.]

| 特徴 | 確認事項 |
|---|---|
| 法形式 | 営業者と TK 投資家の商法上の匿名組合契約 |
| 投資家の可視性 | TK だけでは GK 社員にならないが、他法令、届出、契約、KYC、開示で特定され得る |
| 税務配分 | 営業者／投資家、納税者、契約、支払性質、現行通達で異なる |
| 源泉／国内源泉 | 実際の支払について所得性質、国内源泉、受取人、源泉規定を確認 |
| PE | TK 名称だけで PE／非 PE を結論せず、人員、代理、運用、帰属、国内法、条約を分析 |
| GK との組合せ | GK が営業者となる一つの構成例にすぎない |
| 条約 | 正確な条約を国内分類・手続と併せて逐条確認し、特定の TK 条項または結果を仮定しない |

GK-TK は候補の一つであり、名称だけで法人段階課税、源泉徴収、PE、条約適格性を解消しない。

構造レベルの利用場面は[[real-estate-finance/real-estate-private-credit-japan|private credit]]とクロスチェックする。

## TMK の配当損金算入

TMK は資産流動化法上の特定目的会社であり、配当損金算入は現行租税特別措置法と関連規則の条件付きである。

表の出典注記：資産流動化法は TMK と資産流動化計画、租税特別措置法 67 条の14 は税特例を定める。現行法定要件を市場略語へ単純化しない確認表である。^[出典: https://elaws.e-gov.go.jp/document?lawid=410AC0000000105 および https://elaws.e-gov.go.jp/document?lawid=332AC0000000026.]

| 条件 | 確認事項 |
|---|---|
| TMK／資産流動化計画 | 設立、計画、届出・登記、対象資産、運営を資産流動化法で確認 |
| 67 条の14 | 各事業年度で現行法令・下位規則の全要件を満たす場合に限り損金算入 |
| 分配テスト | 現行法の「90%超」の計算・定義を適用し、会計上の配当性向で代用しない |
| 投資家／金融条件 | 適用される出資、特定社債、借入、所有その他の現行要件を正確に確認 |
| 商品／分配 | 資産計画、特定出資・社債・借入、定款、実際の分配を確認。優先出資を普遍的としない |

TMK は法定証券化ルートの候補の一つで、市場シェア、「主力」、資産数、トランチ、投資家基盤を主張しない。

利用場面の検討に限って[[real-estate-finance/real-estate-private-credit-japan|private credit]]と併読する。

## J-REIT 90%分配ルール

J-REIT（投資法人）の適格分配は、現行の法定要件をすべて満たす場合に限り損金算入され得る。分配可能利益の 90% 超というテストは一条件であり、単独のパススルー規則ではない。

表の出典注記：JPX 2026 ガイドブックは、分配可能利益の 90% 超の分配と資産運用委託を主要導管性要件として説明する。国税庁は適用年度の全要件を満たす場合に限り損金算入されると示す。90% は必要だが唯一の条件ではない。^[出典: https://www.jpx.co.jp/english/equities/products/reits/guidebook/b5b4pj000003984r-att/REIT.pdf および https://www.nta.go.jp/law/shitsugi/hojin/26/05.htm.]

| 特徴 | 確認事項 |
|---|---|
| 法形式 | 投信法上の投資法人 |
| 分配テスト | 分配可能利益の 90% 超は主要要件の一つ。現行法定計算を使用 |
| 効果 | 全要件充足時の適格分配は損金算入され得る。法人税ゼロを保証しない |
| 投資主への分配 | 国内分類・源泉を適用し、条約軽減・免税は正確な特典と手続を要する |
| 遵守 | 発行体・年度ごとに確認し、上場だけから推定しない |
| 資本留保 | 高い分配要件は留保へ影響するが、資金調達は発行体固有 |
| 資産運用 | JPX が説明する別の主要要件。法定・発行体事実を確認 |

90% 超の分配テストは他の全適用要件と併せて留保・分配方針に影響し得るが、それだけで発行体の税務結果は決まらない。発行体の法定計算、損金算入額、留保現金、資金調達開示、投資主段階の取扱いを確認する。分配利回りは[[real-estate-finance/j-reit-dividend-yield-vs-jgb-spread]]で別途読む。

## 租税条約ネットワーク

表の出典注記：以下は条約条項の論点であり「典型税率」ではない。財務省の現行一覧と正確な条約／MLI 統合本文を用い、国税庁の特典・届出手続を完了してから軽減を適用する。^[出典: https://www.mof.go.jp/english/policy/tax_policy/tax_conventions/tax_convetion_list_en.html および https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2888.htm.]

| 条約条項 | 確認事項 |
|---|---|
| 不動産所得 | 正確な条約で源泉国課税の範囲を確認 |
| 譲渡益 | 直接不動産、不動産関連法人、他証券、所有、取引を条約本文で確認 |
| 配当／投資法人分配 | 支払を分類し、条項、税率・閾値、実質的受益者、特典要件を適用 |
| 利息 | 利息該当性、条項、免税、税率、手続を確認 |
| TK | 明示条項と国内分類の相互作用を確認。デフォルト結果を仮定しない |
| 年金／ソブリン | 正確な投資家・所得が条約等を満たす場合だけ適用 |
| LOB／PPT 等 | MLI 影響を含む全特典要件を確認 |
| MAP／仲裁 | 利用可否、範囲、手続は条約ごとに異なる |

適用条約は重要な設計入力になり得るが、国内分類、投資家／実質的受益者、PE、所有、支払性質、濫用防止、手続と併せて検討する。重要度の順位は付けない。

## 一般的なクロスボーダー構造

表の出典注記：構造ごとの確認事項を示し、パススルー、条約軽減、最適経路を約束しない。^[出典: https://www.nta.go.jp/law/tsutatsu/kihon/hojin/14/14_01_01.htm, https://www.jpx.co.jp/english/equities/products/reits/guidebook/b5b4pj000003984r-att/REIT.pdf, および https://www.mof.go.jp/english/policy/tax_policy/tax_conventions/tax_convetion_list_en.html.]

| 構造 | 用途 | 確認事項 |
|---|---|---|
| 外国法人の直接保有 | 直接資産エクスポージャー | 所有者へ不動産所得・譲渡益、申告、源泉、PE、条約を直接適用 |
| 外国 TK 投資家を伴う GK-TK | 日本営業者を通じた契約エクスポージャー | 営業者／投資家配分、支払性質、源泉、PE、事業体分類、条約特典 |
| TMK | 法定資産流動化 | TMK 損金算入、投資家、資産計画、源泉、規制の全要件 |
| 上場 J-REIT | 公開不動産エクイティ | 発行体導管性と保有者の源泉・譲渡益・条約を分離確認 |
| 外国ファンド経由 GK-TK | プール型投資 | 各事業体／投資家層の透明性、実質的受益者、PE、源泉、条約 |
| クロスボーダー不動産クレジット | デット／メザニン／優先／ブリッジ | リターンを分類し、損金、国内源泉、源泉、移転価格／利子制限、条約を確認 |
