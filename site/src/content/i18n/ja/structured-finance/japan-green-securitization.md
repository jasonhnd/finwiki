# 日本のグリーン証券化 — JHFグリーンMBSと根拠の範囲

## TL;DR

今回の調査で公開資料により確認できた中心的な商品は、JHFグリーンMBSである。JHFの現行資料は、グリーンMBSと通常の月次MBSを明確に区別している。グリーンMBSは超過担保を利用しないため、格付との関係も異なる。従来のページでは、この商品を根拠に、未確認の日本のグリーンRMBS、再生可能エネルギー債権ABS、EV ABS、証券化商品のSLB付加条項、Climate Bonds認証、日本と欧州の「グリーニアム」比較へ一般化していた。公開された特定取引とフレームワーク資料がない限り、これらの主張は削除する。

## 1. グリーン・ラベルとストラクチャーは別の論点

[環境省のグリーンボンドガイドライン・ページ](https://greenfinanceportal.env.go.jp/bond/guideline/guideline.html)および[ICMAのグリーンボンド原則](https://www.icmagroup.org/sustainable-finance/the-principles-guidelines-and-handbooks/green-bond-principles-gbp/)は、以下の根拠確認チェックリストを支持している。

| 確認事項 | 必要な根拠 |
|---|---|
| 何にグリーン・ラベルが付されているか | 特定の証券およびフレームワーク |
| 何が適格資産への資金充当を示すか | 資金使途の区分および選定プロセス |
| 調達資金をどのように管理するか | 発行体のフレームワークおよび口座管理プロセス |
| 何が報告されるか | 配分・インパクト報告書、対象期間および方法 |
| 誰がレビューしたか | 特定の外部レビュー報告書および対象範囲 |
| 証券化ストラクチャーは何か | 別途の募集資料、信託資料および格付資料 |

グリーン・ラベルは、信用補完、格付、投資家層、価格を立証するものではない。

## 2. 検証済みのJHFグリーンMBSの範囲

[JHFのグリーンMBS発行計画](https://www.jhf.go.jp/about/investor/shisan_tanpo/green_mbs.html)、[2026 MBS概要](https://www.jhf.go.jp/files/topics/5876_ext_99_0.pdf)、[FY2026 比較資料](https://www.jhf.go.jp/files/topics/5007_ext_99_1.pdf)は、以下の表を裏付けている。

| 特徴 | 確認できる内容 |
|---|---|
| 発行体 | JHF |
| 商品 | JHFが開示したグリーン・フレームワークに基づく特定のグリーンMBSシリーズ |
| 債券 / 信託の仕組み | JHF資料に記載された受益権行使事由の仕組みを備えるJHF債券 |
| 超過担保 | グリーンMBSはOCを設定しない |
| 格付への影響 | 日付が明記されたグリーンMBSの格付を確認し、通常の月次MBSの格付を転用しない |
| 発行データ | 特定のグリーン・シリーズの発行計画、プレセール資料および発行結果を使用する |

## 3. 通常の月次MBSとの比較

[JHFのFY2026 商品比較](https://www.jhf.go.jp/files/topics/5007_ext_99_1.pdf)は、以下の限定的な比較表を裏付けている。

| 項目 | 通常の月次JHF MBS | JHFグリーンMBS |
|---|---|---|
| 超過担保 | 事由発生後の受益権について使用する | 使用しない |
| 格付 | 日付が明記された通常シリーズの格付 | 日付が明記されたグリーン・シリーズの格付 |
| 適格性 | 通常商品条件に基づくFlat 35 プール | 特定資料に記載されたグリーン・フレームワークの適格基準 |
| 根拠 | 通常シリーズの発行結果およびプールデータ | グリーン発行計画、プレセール / 発行結果、フレームワーク報告 |

これはシニア / 劣後トランシェの比較ではない。

## 4. SLBおよび認証に関する主張

[環境省の現行ガイドライン・ページ](https://greenfinanceportal.env.go.jp/bond/guideline/guideline.html)は、証券化商品のSLBまたは認証を主張する場合について、以下のルールを支持している。

| 主張 | 特定案件について最低限必要な根拠 |
|---|---|
| サステナビリティ・リンク条項 | 募集資料に記載されたKPI、SPT、観測日、検証、金銭的効果 |
| クーポン・ステップアップ | 正確な契約金額および対象期間。「典型的な25–50bp」というレンジを設けない |
| Climate Bonds認証 | 特定の認証書、基準の版および検証機関 |
| 外部レビュー | 特定の報告書および対象範囲 |
| 日本での採用 | 定義された取引母集団および日付 |

上記一式がない限り、日本の証券化SLBまたはClimate Bonds認証を受けたSPVが存在するとは主張しない。

## 5. 市場間比較

[環境省のガイドライン・ページ](https://greenfinanceportal.env.go.jp/bond/guideline/guideline.html)と特定の海外制度により、以下の比較方法を支持できる。

| 項目 | 比較ルール |
|---|---|
| フレームワーク | 正確な版と、法的制度 / 任意基準の別を比較する |
| 商品 | 同一の担保およびストラクチャーを比較する |
| 発行額 | 対象期間、通貨、発行額の定義を明確にする |
| 価格 | 日付、通貨、ベンチマーク、平均残存年限、信用力を揃える |
| 検証 | レビュー機関 / 検証機関および保証業務の範囲を明記する |

日本と欧州について、規模、満期、グリーニアムの一般的な序列は記載しない。

## 6. 保留した主張

日本の民間グリーンRMBS、再生可能エネルギー債権ABS、EV ABS、SLB付加条項、認証の採用、投資家需要、グリーニアムについては、公開された特定取引および直接リンクで裏付けられるまで保留する。
