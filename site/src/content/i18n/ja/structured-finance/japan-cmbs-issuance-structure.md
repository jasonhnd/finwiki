# 日本のCMBS発行ストラクチャー — 特定取引の根拠確認ガイド

## TL;DR

従来のページでは、明確な取引集合を定義せずに、TMK / GK-TKの選好、標準的なトランシェ構成、格付、サービサー、2008年以降のデフォルト、2020年以降の物流施設主導の回復を一般化していた。これらの主張は削除した。CMBSは、特定の発行体、担保、ローン、ビークル、ウォーターフォール、サービシング、日付が明記された格付・パフォーマンス資料に基づいて記述する必要がある。

## Wiki内の参照先

本ページは、[[structured-finance/tmk-special-purpose-company-mechanics]]、[[structured-finance/spv-tk-gk-vehicle-japan-tax]]、[[structured-finance/credit-rating-methodology-jcr-r-and-i]]と併せて参照する。

## 1. 特定取引

[JCRの公開ストラクチャード・ファイナンス格付一覧](https://jcr.co.jp/en/ratinglist/sf_sf/)は調査の入口の一つである。以下の表は、必要な根拠一式を示す。

| 項目 | 必要な公開根拠 |
|---|---|
| 発行体 / ビークル | 募集資料および法的資料 |
| 借入人 / スポンサー | ローン資料および取引開示 |
| 担保 | 不動産 / 抵当権 / 信託受益権の定義 |
| ローン条件 | 元本、満期、元本返済、コベナンツおよび遡求 |
| 債券 / 持分 | クラス条件および支払順位 |
| 格付 | 日付が明記されたクラス別の格付アクションおよび適用された格付基準の版 |

## 2. ビークルの範囲

[資産の流動化に関する法律](https://laws.e-gov.go.jp/law/410AC0000000105)が定めるのは、以下の表に示すTMKの法的範囲であり、CMBS市場における選好ではない。

| ビークルに関する主張 | 必要な根拠 |
|---|---|
| TMK | 特定の発行体、届出 / 計画および募集資料 |
| GKとTKの組み合わせ | 設立資料、TK契約および資産関連資料 |
| 信託受益権 | 信託契約および譲渡 / 募集条件 |
| 公募または上場 | 募集届出および取引所記録 |
| 税務 / 会計 | 現行法および取引固有の分析 |

## 3. キャッシュフローとサービシング

[JCRの格付方法ライブラリー](https://www.jcr.co.jp/en/rrinfo/meth_sf/)は、以下の分析チェックリストを支持している。

| 項目 | 特定取引について必要な根拠 |
|---|---|
| 不動産キャッシュフロー | レントロール、費用、空室、評価基準日 |
| デットサービス | 金利、元本返済、バルーン条件 |
| ウォーターフォール | 費用、利息、元本および損失配分 |
| 準備金 / ヘッジ | 資金拠出、用途、カウンターパーティおよび交代条項 |
| サービサー / スペシャル・サービサー | 選任、移管事由および権限 |
| リファイナンス / 売却 | 前提および契約上の時期 |

## 4. 時系列分析

[JSDAの証券化市場調査](https://www.jsda.or.jp/en/statistics/securitization-market/)は、以下の方法を支持している。

| 主張 | 必要な根拠 |
|---|---|
| 発行動向 | 定義されたJSDAの区分、対象期間および改訂 |
| デフォルト | 特定のローン / 債券に関する事象および日付 |
| 損失 / 回収 | 受託者、サービサーまたは格付機関の開示 |
| 物件種別の傾向 | 特定の取引集合および基準日 |
| 「閉鎖」 / 「回復」 | 定義された閾値および計算方法 |

## 5. 保留した主張

ビークルの優位性、標準的なトランシェ、格付機関の組み合わせ、投資家層、デフォルト増加の規模、現在の回復については、公開された明確な取引母集団がない限り保留する。
