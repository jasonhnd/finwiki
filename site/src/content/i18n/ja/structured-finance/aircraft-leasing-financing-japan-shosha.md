# 航空機リース・ファイナンス — 検証済みの日本関連プラットフォーム

## TL;DR

引用した各社のページから、複数の日本関連航空機リース事業と、日付が明記されたSMFGの買収開示を確認できる。一方、これらの資料は、保有機数の順位、JOL/JOLCOにおける標準的なレバレッジ・期間・投資採算、市場リーダーの序列、または一般化された航空機ABSの構造を裏付けるものではない。このため、本ページは、確認できた企業関係と、特定取引について確認すべき根拠のチェックリストのみを記載する。

## Wiki内の参照先

本ページは、[[structured-finance/japan-securitization-product-matrix]]および[[structured-finance/spv-tk-gk-vehicle-japan-tax]]と併せて参照する。

## 1. 検証済みのプラットフォーム

[Mitsubishi HC Capitalの航空事業ページ](https://www.mitsubishi-hc-capital.com/english/corporate/business/aviation.html)および各社の情報源は、以下の表を裏付けている。

| プラットフォーム / 事業 | 公開一次資料 | 確認できる範囲 |
|---|---|---|
| Jackson Square Aviation | Mitsubishi HC Capitalの航空事業ページ | Mitsubishi HC Capitalが説明するグループの航空機リース・プラットフォーム |
| SMBC Aviation Capital | [日付が明記されたSMFGの買収開示](https://www.smfg.co.jp/news_e/html/e200199/e200199_01.html) | 当該開示日時点の取引および所有構造。現在の所有関係は再確認が必要 |
| SMFLの航空事業 | [SMFLの強み](https://www.smfl.co.jp/english/corporate/strength/) | SMFLの事業の一つとして航空分野が記載されている |
| Aviation Capital Group | [Tokyo Centuryの航空機ファイナンス・ページ](https://www.tokyocentury.co.jp/jp/business/service/aviation/finance.html) | Tokyo Centuryの航空事業にACGが明記されている |
| ORIXの航空機・船舶事業 | [ORIXの事業ページ](https://www.orix.co.jp/grp/en/about/businesses/aircraft_ships/) | ORIXが説明する航空機・船舶のリースおよび関連サービス |

保有機数や「top-N」の結論は示さない。

## 2. ファイナンス構造の根拠

[Mitsubishi HC Capitalの航空事業ページ](https://www.mitsubishi-hc-capital.com/english/corporate/business/aviation.html)は、共通のファイナンス構成を示すものではない。特定取引について、以下の項目を確認する。

| 項目 | 必要な根拠 |
|---|---|
| 所有者 / 賃貸人 / 賃借人 | 締結済みのリース契約および所有権関連資料 |
| デット | 融資額、貸付人、担保、元本返済条件およびコベナンツ |
| エクイティ / 投資家持分 | 募集資料および組合契約 / 出資関連資料 |
| 税務上の取扱い | 現行法ならびに投資家と取引の具体的事実 |
| 購入価格 / 残存価値 | 鑑定評価、整備状況および売却前提 |
| 通貨 / ヘッジ | リース通貨、借入通貨およびヘッジ契約 |

## 3. 商品の区別

[ORIXの航空機・船舶事業ページ](https://www.orix.co.jp/grp/en/about/businesses/aircraft_ships/)が示すように、企業の活動は複数のサービスにまたがり得る。以下の表により、商品を混同しないようにする。

| 商品 | 最低限必要な根拠 |
|---|---|
| オペレーティング・リース | 特定の航空機、所有者、賃借人およびリース契約 |
| JOL / JOLCO | 特定の投資家向け募集、法的形態、デットおよび税務分析 |
| 航空機担保付融資 | 融資契約および担保関連資料 |
| 航空機ABS | 特定の発行体、資産プール、債券、ウォーターフォールおよび格付資料 |
| セール・アンド・リースバック | 売買契約およびリース契約 |

## 4. 保留した主張

保有機数の順位、市場シェア、50–80%のレバレッジ、8–12年の期間、投資家利回り、税務メリット、「リーダー」とする表現は、公開された特定取引または日付と母集団が明確な資料で裏付けられるまで保留する。
