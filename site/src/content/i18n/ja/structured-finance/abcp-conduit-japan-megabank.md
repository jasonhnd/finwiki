# ABCPコンデュイット（資産担保コマーシャルペーパー）— 日本における根拠確認ガイド

## TL;DR

今回の調査では、従来記載していたMUFG・SMBC・みずほのプログラム名、ビークル形態、残高、100%の流動性枠、最高位の短期格付、縮小の経緯、海外投資家比率、価格レンジを裏付ける、安定して参照可能な公開プログラム資料を確認できなかった。このため、それらの主張は削除した。ABCPプログラムは、個別プログラムの資料、流動性関連資料、資産関連資料、格付資料に基づいて読み解く必要がある。

## 1. プログラムの特定

[JCRのストラクチャード・ファイナンス格付方法ライブラリー](https://www.jcr.co.jp/en/rrinfo/meth_sf/)は分析の出発点となる。以下の表は、特定プログラムについて確認すべき根拠を示す。

| 項目 | 必要な公開根拠 |
|---|---|
| 法的な発行体 / コンデュイット | プログラム資料または格付資料 |
| スポンサー / 管理者 | 各法人を明記した最新資料 |
| ビークル / 法域 | 設立資料およびプログラム資料 |
| 発行通貨 / 市場 | 日付が明記された発行記録 |
| 残高 | 日付が明記されたプログラム資料または規制開示 |

## 2. 資産と信用・流動性補完

[JCRのストラクチャード・ファイナンス格付に関する一般的方法](https://www.jcr.co.jp/en/pdf/dm28/General_Methodology20210802.pdf)は、以下の根拠確認チェックリストを支持している。

| 項目 | 特定プログラムについて必要な根拠 |
|---|---|
| 適格資産 | 買取基準 / 適格基準およびプール報告書 |
| 信用補完 | 金額、提供者、条件および除外事項 |
| 流動性枠 | コミットメント額、実行条件、除外事項および終了条件 |
| 満期 / ロールオーバー | CPの条件およびプログラムの仕組み |
| カウンターパーティ | 口座、ヘッジ、流動性および交代条項 |

日付が明記された格付アクションを確認せずに、流動性が全額補完されている、またはスポンサーの格付がCPにそのまま移転すると想定してはならない。

## 3. 格付とストレス履歴

[JCRの公開格付一覧](https://jcr.co.jp/en/ratinglist/sf_sf/)および個別プログラムの開示により、以下を確認する。

| 主張 | 必要な根拠 |
|---|---|
| 格付 | 特定のCP / プログラム、日付および適用された格付基準の版 |
| 流動性枠の実行 | 日付が明記されたスポンサーまたはコンデュイットの開示 |
| 不履行 / 支援 | 契約上の事象および公開された結果 |
| 規制上の自己資本 / 流動性への影響 | 適用規則およびスポンサーの開示 |
| 過去の縮小 | 明確に定義されたプログラム母集団、日付および金額 |

## 4. 投資家と価格に関する根拠

[JSDAの証券化市場ページ](https://www.jsda.or.jp/en/statistics/securitization-market/)は市場調査の入口だが、個別の情報源がなければ以下の項目を裏付けるものではない。

| 主張 | 必要な根拠 |
|---|---|
| 投資家区分 / 海外投資家比率 | 配分または保有状況の開示 |
| 期間 | 特定のCPの条件 |
| クーポン / スプレッド | 日付とベンチマークが明記された発行結果 |
| クロスカレンシー取引の採算 | 実際の調達条件、スワップ条件および観測日 |
| タームABSとの比較 | 通貨、平均残存年限および信用力を揃えた比較対象 |

## 5. 保留した主張

スポンサー順位、市場のピーク、100%のバックストップ、投資家構成、価格については、公開された特定プログラムの資料および直接的な情報源で裏付けられるまで保留する。
