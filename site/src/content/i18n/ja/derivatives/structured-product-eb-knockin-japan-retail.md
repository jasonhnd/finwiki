# 日本の個人向けEBノックイン仕組商品

## 要点

EB（他社株転換可能債券）は、参照株価と契約条件に応じて、金銭ではなく発行者とは別の会社の株式で償還されることがある複雑な債券である。ノックイン条項がある場合、所定の観察期間中に参照価格が指定バリアへ到達したかどうかが償還結果に影響し得る。経済的には、債券と条件付の売りプットを組み合わせたものに近い設計もあるが、クーポン、バリア、観察方法、期限前償還および損失の結果は銘柄ごとに異なる。日本証券業協会（日証協）は、購入前にこれらの条件、発行者信用リスクおよび数値によるペイオフ例を確認するよう促している。金融庁のモニタリングは、販売会社による顧客本位の商品・販売ガバナンスを対象としている。

### 主要メカニズム

次表は、日証協のEB資料に基づく目論見書の確認項目である。裏付けのない「典型的」なクーポン、バリア、満期およびバスケットの範囲は意図的に記載していない。 ^[Sources: https://www.jsda.or.jp/about/hatten/risk/eb/index.html; https://disclosure2.edinet-fsa.go.jp/.]

| 構成要素 | 銘柄ごとに確認する項目 |
|---|---|
| 法的形態と発行者 | 発行者、準拠法、発行ビークルおよび発行者信用リスク。 |
| 通貨 | 発行、利払いおよび償還の各通貨。 |
| 満期 / 期限前償還 | 契約上の満期と、すべての期限前償還の観察・条件。 |
| 原資産・参照対象 | 参照する株式、指数またはバスケットと、正確な価格情報源。 |
| 当初参照価格 | S₀の定義と決定日。 |
| ノックイン | バリア水準、観察期間、観察方法および適用時の効果。 |
| クーポン | 利率とすべての支払条件。 |
| 償還 | 金銭または株式交付の算式、端数処理および評価日。 |

### 複数参照型とワースト・オブ型

次表は文書確認のためのチェックリストである。大和証券が公開するリターン分布ページでは、同社が過去に取り扱ったノックイン型EBを単一参照と複数参照に区分していることを確認できるが、各銘柄の集計算式は当該銘柄の文書で確認しなければならない。 ^[Sources: https://www.daiwa.jp/products/bond/st/sheet/; https://disclosure2.edinet-fsa.go.jp/.]

| 特徴 | 銘柄ごとの確認事項 |
|---|---|
| 参照対象の数 | 目論見書で確認し、一般的な範囲を仮定しない。 |
| 集計規則 | ペイオフは最も成績の悪い参照対象、平均、または別の算式を用いるか。 |
| 依存関係 | 評価またはシナリオ分析で、どの依存関係の仮定を用いているか。 |
| シナリオ分析 | 明記された算式からペイオフを計算し、参照対象の数だけを根拠に通常のポートフォリオ分散効果を推定しない。 |

ワースト・オブ規則を採用する銘柄では、契約が定める最も弱い参照対象の経路を評価する。本項目は、投資家一般がこの特徴をどのように認識していたかを主張しない。

### 自動期限前償還機能

次表は仮想的な三時点のスケジュールであり、市場慣行を示すものではない。実際の観察日、判定水準の推移、クーポンおよび償還額は目論見書で確認する。 ^[Sources: https://www.jsda.or.jp/about/hatten/risk/shikumisai/index.html; https://disclosure2.edinet-fsa.go.jp/.]

| 例示する観察時点 | 契約条件を満たした場合 |
|---|---|
| 最初の観察 | 明記された期限前償還算式を適用する。 |
| その後の観察 | ステップダウンまたはステップアップする判定水準と、明記されたクーポンの扱いを適用する。 |
| 満期 | それ以前に償還されていなければ、最終的な金銭償還または株式交付の算式を適用する。 |

期限前償還が行われると、契約算式に基づく投資家のエクスポージャーは終了する。各当事者にとっての価値は実現した価格経路と評価によるため、一律に利益と表現すべきではない。

### 投資家ポジションの経済的等価性

```
EBノックイン債のロング ≈ 債券のロング + 原資産のダウン・アンド・イン・プットのショート
```

プットのショートは、次の源泉となる。

- 上乗せクーポン（受け取るオプション・プレミアム）
- テールリスクへのエクスポージャー（バリア未満で顕在化する非連続的な損失形状）

### 満期時のペイオフ例

次表は、S₀ = 1,000、ノックイン・バリア = 600、行使価格 = 1,000、元本 = JPY 1,000,000とする仮想的な単一銘柄EBの算術例である。株式交付時の価値が元本を下回り得るという日証協の注意喚起を示すもので、実際の顧客取引ではない。クーポンの扱いは銘柄ごとに異なるため省略した。 ^[Source: https://www.jsda.or.jp/about/hatten/risk/eb/index.html.]

| シナリオ | 最終株価 | 結果 |
|---|---|---|
| 契約上の株式交付条件に該当しない | 850 | 当該銘柄の金銭償還算式を適用する。 |
| バリア到達、最終株価800 | 800 | 仮定した条件が1,000株の交付を求める場合、その価値はJPY 800,000となる。 |
| バリア到達、最終株価500 | 500 | 同じ仮想的な交付算式では、株式価値はJPY 500,000となる。 |
| バリア到達、最終株価200 | 200 | 同じ仮想的な交付算式では、株式価値はJPY 200,000となる。 |

### ノックインの観察文言が重要

日証協は、所定の期間中に参照対象が指定されたノックイン価格へ到達すると、ノックイン条項が適用され得ると説明している。どの観察値が判定対象となるかは、目論見書で定義しなければならない。 ^[Sources: https://www.jsda.or.jp/about/hatten/risk/eb/index.html; https://disclosure2.edinet-fsa.go.jp/.]

| 目論見書の文言 | 確認事項 |
|---|---|
| 観察期間 | 開始・終了時刻と、どの市場カレンダーを適用するか。 |
| 日中または「一度でも」の判定 | どの価格情報源と適格な観察値がトリガーとなるか。 |
| 終値による判定 | どの市場の終値と調整条項を適用するか。 |
| 指定日による判定 | どの日付と市場障害時の代替規定を適用するか。 |

観察頻度が変われば、条項を発動させ得る価格経路の集合も変わる。価格およびリスクへの影響は、当該銘柄の全条件に基づいて計算する必要がある。

## ディーラーの価格評価要素

次表はモデル検証のチェックリストであり、普遍的な価格影響表ではない。大和証券の公開銘柄資料は、参照指数、予想変動率および円金利を、ある仕組債の中途売却価格に影響する要因として挙げている。その他の入力値は、当該銘柄と評価モデルから根拠を示す必要がある。 ^[Sources: https://www.daiwa.jp/content/dam/daiwasecurities/products/pdf/bond/200124_2.pdf; https://disclosure2.edinet-fsa.go.jp/.]

| 入力値 | 評価上の確認事項 |
|---|---|
| 原資産のインプライド・ボラティリティ | どのサーフェス、日付およびモデルを用いるか。 |
| 相関（バスケット） | 参照対象間の依存関係をどのように較正するか。 |
| 配当利回りとコーポレート・アクション | 配当、株式分割および調整をどう扱うか。 |
| 借株コストと流動性 | どのヘッジ仮定をモデルに組み込むか。 |
| 発行者のクレジット・スプレッド | 発行者の無担保信用リスクをどう反映するか。 |
| イールドカーブ | どの割引曲線と調達曲線を用いるか。 |
| バリアと観察規則 | 経路依存性と観察方法が価値にどう影響するか。 |
| 自動期限前償還の判定水準 | 期限前償還が期待キャッシュフローをどう変えるか。 |
| 満期 | 期間が債券部分と組込オプションの価値にどう影響するか。 |

### ディーラーの手数料負担

価格、モデル価値、アレンジャーの経済性および販売会社の報酬は銘柄ごとに異なる。引用資料は一律の3～10%という手数料範囲を裏付けないため削除した。当該銘柄と販売会社の文書を確認する。

### ヘッジ

次表は、公開資料が裏付ける事項と、取引固有の証拠がなお必要な事項を分ける。日証協の一般的な構造は発行者によるカバー取引を示し、SMBC日興証券の公開調査報告書はEBの組込プットから生じる価格変動リスクをヘッジするための参照株式売買を説明している。どちらの資料も、他のディーラーの実際のポジションや、普遍的なバック・ツー・バック取引を裏付けるものではない。 ^[Sources: https://www.jsda.or.jp/about/hatten/risk/shikumisai/index.html; https://www.smbcnikko.co.jp/news/release/2022/pdf/220624_02.pdf.]

| リスクまたは段階 | 証拠の境界 |
|---|---|
| 発行者のカバー取引 | 日証協の一般図は、スワップハウスとのカバー取引が存在することを裏付ける。 |
| 参照株式によるヘッジ | 引用したSMBC日興証券の報告書は、ノックイン価格または権利行使価格付近での取引を含め、EBのプット・リスクをヘッジする一例として参照株式売買を裏付ける。 |
| その他のオプション、相関、金利または信用ヘッジ | 取引、マンデートまたはリスク開示が必要であり、使用商品やヘッジ比率を推定しない。 |
| 残余リスク | リスクが相殺または保有されたと主張する前に、公開されたポジションまたはリスク証拠を必要とする。 |

銘柄を特定した発行・ポジションの証拠がない限り、個別株のヘッジフローに関する結論を導かない。

## 過去局面の検証窓

次表は、銘柄別目論見書、参照価格、苦情またはモニタリング・データを用いて検証できる期間を定める。引用する集計資料では裏付けられないため、広範なノックイン、顧客損失の総額または因果関係を主張するものではない。 ^[Sources: https://www.fsa.go.jp/news/r4/kokyakuhoni/fdreport/fd_202306.html; https://www.jsda.or.jp/about/hatten/risk/eb/index.html.]

| 検証期間 | 必要な証拠 |
|---|---|
| 2018～2019年の株式ボラティリティ | 特定の残存銘柄、バリア、観察規則および価格経路を確認する。 |
| 2020年三月の市場ショック | ノックインに分類する前に、各銘柄と日付を特定した原資産価格を対応付ける。 |
| 2020～2021年の発行体固有の値動き | 株価変動だけから債券保有者の結果へ外挿しない。 |
| 2022年の株式下落 | 定義した発行サンプルとその契約条件だけから数値化する。 |

### モニタリングと行政処分の境界

金融庁は顧客本位の業務運営の枠組みの下、2022事務年度に仕組債の商品・販売ガバナンスをモニタリングし、複数社に共通し得る論点を公表した。このテーマ別報告書は個社に対する行政処分ではない。このため、野村證券、SMBC日興証券および大和証券にEB関連の業務改善命令が出されたとする従来の表は削除した。処分を記載する場合は、金融庁または証券取引等監視委員会の記録で、正確な法人、日付、対象行為および法的根拠を確認しなければならない。

### 販売会社の対応に関する境界

販売会社の対応は、日付を明示した各社開示で確認しなければならない。本項目が用いる集計資料は、販売停止、顧客基準、事業撤退または商品構成変更の完全な一覧を裏付けない。

### 販売量への影響

定義された発行データセットがない限り、個社または業界全体で80%減少したとの数値は主張しない。

### 適合性評価

次表は、顧客本位の業務運営と複雑商品のリスクに関する論点から作成した検証用チェックリストであり、一律の規則本文でも、固定的な年齢・比率基準でもない。 ^[Sources: https://www.fsa.go.jp/policy/customer_first/index.html; https://www.fsa.go.jp/news/r4/kokyakuhoni/fdreport/fd_202306.html; https://www.jsda.or.jp/shijyo/seido/jishukisei/words/0248.html.]

| 検証領域 | 保存すべき証拠 |
|---|---|
| 知識 / 経験 | 顧客が実際のペイオフと損失のメカニズムを理解しているかの評価。 |
| リスクと目的の整合 | 商品の損失、流動性および発行者信用リスクを、顧客の目的と負担能力に結び付ける。 |
| 顧客の状況 | 現行法、日証協規則および会社の文書化された手続を適用する。本項目では一律の年齢基準を示さない。 |

## 転換社債との比較

次表はペイオフの大枠を比較するもので、購入者、適合性または開示区分を一律に定めるものではない。日証協のEB資料はEBの償還リスクを裏付け、大和証券のCBページは、転換社債の保有者が銘柄条件に基づいて転換するかどうかを選択できることを示す。正確な条件はそれぞれの目論見書に従う。 ^[Sources: https://www.jsda.or.jp/about/hatten/risk/eb/index.html; https://www.daiwa.jp/products/bond/cb/; https://disclosure2.edinet-fsa.go.jp/.]

| 比較軸 | ノックインEBの例 | 転換社債の例 |
|---|---|---|
| 販売の例 | 適合性・商品規則に従い、個人向け証券チャネルで販売される場合がある | 銘柄に応じ、機関投資家向けまたは公募の証券チャネルで販売される場合がある |
| 行為規範 | 顧客区分と募集区分による | 顧客区分と募集区分による |
| 組込デリバティブの略式表現 | 一部の設計は、債券と条件付の売りプットに分解できる | 転換権は、投資家が保有する株式オプションとして分析できる |
| 株式エクスポージャーの方向 | 明記された金銭・株式償還算式を通じた契約上の下方リスク | 明記された転換権を通じた上方余地 |
| テールリスク | 株式交付価値が元本を大きく下回り得ることに加え、発行者信用リスクがある | 債券価値は下落し得て、発行者のデフォルトは回収を毀損し得る。転換条件により株式感応度も生じる |
| 開示資料 | 目論見書、契約締結前交付書面および現行行為規範 | 目論見書 / 募集文書および現行証券規則 |

ペイオフの略式表現として、一部のノックインEBはクーポンと引き換えに条件付の株式下方リスクを負い、転換社債は保有者に株式連動の転換権を与え得る。いずれも目論見書が優先し、この略式表現によって発行者信用、流動性または評価リスクがなくなるわけではない。
