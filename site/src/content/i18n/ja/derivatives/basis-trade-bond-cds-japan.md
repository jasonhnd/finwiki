# 日本の債券・CDS ベーシス取引

## TL;DR

日本の債券・CDS ベーシスは、企業の CDS スプレッドと、明示した国債またはスワップのベンチマークに対する、条件を揃えた現物債のクレジット・スプレッドを比較する。本項の慣行では、**ベーシス = CDS スプレッド − 債券スプレッド**とする。ベーシスのクォートがマイナスなら、資金調達した債券ロングとプロテクション買いの比較を検討できるが、「無償のキャリー」ではない。債券の選択、ヘッジ比率、CDS の受渡条件、経過利子、回収率、資金調達、証拠金、取引相手リスク、流動性、税、資本の全てが結果に影響する。ここで引用する公開資料には、日本企業について実行可能な債券・CDS の完全なパネルがないため、事象ごとの方向、頻度、参加者順位、実現収益は市場の事実ではなく、検証すべき問いとして扱う。

## Wiki 内の位置付け

本項は、[[derivatives/INDEX|デリバティブ索引]] のうち、[[derivatives/japan-cds-market-overview|日本の CDS 市場概要]] と [[derivatives/cds-japan-corporate-spread-mechanics|日本企業 CDS のスプレッド構造]] を補完する裁定・相対価値の項目である。アセット・スワップ価格の基準となるスワップ・カーブは [[derivatives/japan-irs-market|日本の IRS 市場]]、円の資金調達費用は [[derivatives/yen-basis-swap-market|円ベーシス・スワップ市場]]、円でのベーシス取引に参加する米ドル調達主体へ影響する米ドル・円の資金調達関係は [[derivatives/cross-currency-basis-swap-japan|日本の通貨ベーシス・スワップ]] と併読する。

現物債については、債券と資金調達の背景を扱う [[finance/INDEX|ファイナンス索引]]、[[finance/japan-convertible-bond-mechanics|転換社債の仕組み]]、[[money-market/INDEX|短期金融市場索引]] を参照する。[[banking/INDEX|銀行索引]]、[[insurance/japan-life-insurance-alm-overview|日本の生命保険 ALM]]、[[securities/japan-prime-brokerage-and-institutional-financing|プライム・ブローカレッジと機関向けファイナンス]] は周辺の機関投資家環境を説明するが、特定のベーシス・ポジションの保有者を示すものではない。

### 定義

```
債券・CDS ベーシス = CDS スプレッド − 同一期限の債券 Z スプレッド（またはアセット・スワップ・スプレッド）
```

符号表は、参照対象と期間を揃えた通常の比較に従う。これは定義であり、摩擦のない裁定を実行できる証拠ではない。^[Sources: https://www.isda.org/2014/06/30/2014-credit-derivatives-definitions/; https://www.bis.org/publ/qtrpdf/r_qt0712e.pdf.]

| 符号 | 解釈 |
|---|---|
| マイナス・ベーシス | CDS スプレッド < 債券スプレッド。全ての調整後に、資金調達した債券ロング・プロテクション買いの組合せを検討し得る |
| ゼロ・ベーシス | 純粋な裁定均衡（理論上） |
| プラス・ベーシス | CDS スプレッド > 債券スプレッド。債券借入れと CDS 条件を満たす場合、逆方向の組合せを検討し得る |

### ベーシスがゼロにならない理由

摩擦がなければベーシスはゼロとなるが、現実の摩擦により、ベーシスは持続し、時点によって変化する。

| 摩擦 | 必要な取扱い |
|---|---|
| 債券の資金調達費用 | 実行可能な金利、ヘアカット、満期、担保条件、バランスシート費用を用いる |
| クレジット事由の対象差 | 受渡適格債務、リストラクチャリング条件、優先順位、参照組織を揃える |
| 受渡選択権 | 符号を固定せず、適用される受渡適格債務の選択権を評価する |
| 取引相手リスク | 担保、ネッティング、証拠金、デフォルト、再構築費用の条件を含める |
| 流動性の非対称性 | 両レッグについて、同時点の実行可能なクォートと数量を用いる |
| 規制資本費用 | 実際の取引パッケージに、当該機関へ適用される健全性規制を適用する |
| 税務・会計 | 両レッグの認識、源泉徴収、評価、報告を揃える |

### 取引構造

| レッグ | 行動 |
|---|---|
| 現物債ロング | 参照発行体の債券を額面またはその近辺で買い、レポで資金調達する |
| CDS プロテクションのショート（すなわちプロテクション買い） | クレジット事由に対するプロテクションのランニング・スプレッドを支払う |
| ネット・キャリー | 債券利回り − 資金調達金利 − CDS プレミアム |

画面上の債券スプレッドが CDS スプレッドを上回れば、明示した費用控除後にモデル上のプラス・キャリーを示す場合がある。しかし、債券と CDS は債務範囲、回収、流動性、資金調達、取引相手エクスポージャー、決済が異なり得るため、リスクのない収益を固定するものではない。

### 損益の分解

```
日次損益 ≈（債券の経過収益 − レポ資金調達費用）−（CDS プレミアムの経過分）
           + （債券価格 − CDS プロテクション価値）の時価変動
```

時価変動の方向は、明示したベーシスの符号、スプレッド DV01 のヘッジ比率、経過利子、回収率、資金調達の扱いによって異なる。両レッグのデュレーションと契約条件が揃っていなければ、表面的なベーシス変動だけでは判断できない。

### 必要な保有期間

評価期間を明示する必要がある。満期保有の分析では債券償還と CDS の満期・決済をモデル化し、途中で解消する場合は実行可能な反対売買価格と資金調達の終了条件を用いる。引用した集計資料は、ファンドが日本のポジションを歴史的にどのように保有・ロールしたかを示していない。

## 資金調達費用の考慮

債券レッグには資金調達が必要である。再現可能な取引モデルでは、各資金調達項目を明示する。

| 資金調達源 | 費用要因 |
|---|---|
| レポ（相対またはトライパーティ） | 実行可能な金利、ヘアカット、担保、満期、差替え、クローズアウト条件 |
| JGB 担保の GC レポ | 実際の資金調達経路で JGB 担保を使う場合のみ関係する。担保変換があれば特定する |
| 対象社債の SC レポ | その債券が受入れ対象かを確認し、クォート、数量、ヘアカット、期間を記録する |
| 銀行のバランスシート調達 | 機関固有の資金移転、流動性、資本、バランスシート費用 |
| プライム・ブローカー調達 | 契約上の調達スプレッド、ヘアカット、適格担保、証拠金、終了条件。[[securities/japan-prime-brokerage-and-institutional-financing|プライム・ブローカレッジ]]を参照 |

マイナス・ベーシスのクォートは、実行可能な利益指標ではない。閾値は、同一時点の債券・CDS クォート、ヘッジ比率、資金調達費用一式、取引費用、証拠金、資本、出口の前提によって決まる。

## レポ利用可能性の制約

レポを利用できるかは、選択した債券と日付について確認する必要がある。引用した集計資料は、日本の社債と JGB について時点を問わない流動性順位を裏付けない。

| 債券区分 | 必要な証拠 |
|---|---|
| JGB（オン・ザ・ランとベンチマーク） | 日付付きの GC・SC クォート、数量、該当する日本銀行オペのデータ |
| JGB（オフ・ザ・ラン） | 銘柄別クォート、フェイル、スペシャル化、利用可能な数量 |
| 日本の投資適格社債（大規模発行体） | 債券別の貸し手、クォート、ヘアカット、満期、実行可能な数量 |
| 日本の投資適格社債（中小発行体） | 同じ債券別の証拠。発行体規模は流動性の代理変数ではない |
| 日本のハイイールド社債 | 資金調達を利用できる直接の証拠。「レポなし」とは仮定しない |

本項で用いた公開資料は、「Tier 1」の境界、一般的な資金調達経路、米ドルまたはユーロ取引との相対的な拡張性を示していない。こうした主張には、日付付きの取引または資金調達単位のデータが必要である。

### バーゼル III レバレッジ比率

レバレッジ・エクスポージャーは、機関、記帳主体、ネッティング・セット、会計処理、適用される健全性規制によって異なる。クレジット・ヘッジだけではレバレッジ比率上の相殺を立証できないが、引用資料はディーラーの選好や、それに伴うベーシスの方向を定量化していない。

### リスク加重資産（RWA）

| 構成要素 | 影響 |
|---|---|
| 債券レッグ | 銀行勘定・トレーディング勘定の区分と、適用される信用・市場リスクの扱いを確認する |
| CDS レッグ | 必要に応じて、取引相手信用リスク、CVA、市場リスク、担保の扱いを確認する |
| ネット・ヘッジの認識 | 適用される標準的手法またはモデル方式に従い、完全な相殺を仮定しない |

パッケージの RWA とレバレッジへの影響は、機関ごとの計算を必要とする。集計資料は、ディーラーの在庫保有行動を立証しない。

### 単一取引相手への与信限度

大口エクスポージャーと取引相手限度は、記帳主体と法域によって異なる。プロテクション売り手である CDS の取引相手は、実際に同じ法人でない限り、参照組織とは別である。集約とネッティングは、適用規則に従う。

### 流動性カバレッジ比率（LCR）

LCR の扱いは、対象債券が HQLA に該当するか、適用される区分とヘアカット、担保設定、現金流出、担保、デリバティブのキャッシュフローによって異なる。この計算なしにパッケージ全体の LCR の符号を推論しない。

## 日本固有の政策・市場調査の基準点

次の表は、公開された政策・インフラの日付を示す。ベーシスの方向は決めず、結論には条件を揃えた現物債・CDS のデータセットが必要である。^[Sources: https://www.jpx.co.jp/jscc/en/otc/member_cds.html; https://www.boj.or.jp/en/mopo/mpmdeci/index.htm.]

| 期間 | ベーシス調査の公開基準点 |
|---|---|
| 七月 2011 年 | JSCC が CDS 清算を開始。JSCC 統計は、公表された清算対象範囲に限って用いる |
| 2013-2015 年 | 日本銀行の量的・質的金融緩和に関する決定と JGB 市場データに調査期間を合わせる |
| 2016 年 | マイナス金利と YCC の導入に調査期間を合わせる |
| 2020 年 | COVID 市場ショックと日本銀行の措置を、条件を揃えた商品で検証する |
| 2022-2023 年 | 日付付きの YCC 修正を検証し、2023 年を YCC の終了とは扱わない |
| 三月 2024 年以降 | 金融政策の枠組み変更と、その後の観測値を検証する |

## COVID 第 1 四半期・2020 年のベーシス変動

中央銀行と BIS の公開資料は、三月 2020 年の深刻な現物債の流動性ストレスと政策対応を記録するが、日本企業について銘柄別に完全な CDS・債券ベーシス系列を提供していない。このため、次の表は日付付きの検証枠組みであり、変動の順位や特定のベンチマーク銘柄に関する主張ではない。^[Sources: https://www.boj.or.jp/en/mopo/mpmdeci/mpr_2020/index.htm; https://www.bis.org/publ/bisbull2.htm; https://www.bis.org/publ/qtrpdf/r_qt2012.htm.]

| 検証期間 | 比較する証拠 |
|---|---|
| 二月下旬 2020 年 | 世界的なリスク再評価に合わせ、現物債、CDS、資金調達の指標を比較する |
| 三月上旬から中旬 2020 年 | 一方のレッグからベーシスを推論せず、ビッド・アスク、実行可能なクォート、資金調達条件を確認する |
| 日本銀行の三月 2020 年決定 | 日本銀行の措置と日付付きの現物債・CDS の観測値を揃え、直ちに因果関係を推論しない |
| 四月から六月 2020 年 | 発行体、債券、CDS 期間、資金調達費用ごとに収束を検証する |
| 2020 年後半 | 同じ商品を用い、得られたベーシスをショック前の標本と比較する |

2008-2009 年との比較、デュレーション推計、実現取引収益には、定義した発行体標本、実行可能な価格、資金調達費用が必要である。前記の公開資料は、そうした結果を立証しない。

## 2022-2023 年の日本銀行 YCC 修正

次の表は、日本銀行の決定日を観測可能な基準点として用いる。ベーシスへの影響は、条件を揃えた現物債と CDS の観測値を必要とする調査上の問いであるため、自動的な方向やラグを仮定しない。^[Source: https://www.boj.or.jp/en/mopo/mpmdeci/index.htm.]

| 日本銀行の決定 | ベーシス調査の確認点 |
|---|---|
| 十二月 2022 年の YCC 変動幅修正 | 決定前後の JGB カーブ、現物債スプレッド、CDS クォート、資金調達を比較する |
| 七月 2023 年の YCC 運用修正 | 公表された決定期間を用い、条件を揃えた商品比較を繰り返す |
| 十月 2023 年のさらなる柔軟化 | リスクフリー・カーブの再評価を、発行体信用と流動性の影響から分離する |
| 三月 2024 年の金融政策枠組み変更 | 固定的な正常化期間を仮定せず、決定後の観測値を検証する |

現物債と CDS の先行・遅行方向は、商品ルールではなく検証可能な仮説である。同期したクォートと流動性調整を用い、各イベント期間について推定すべきである。

### 参加者に関する証拠の限界

BIS と JSCC の集計は、転換社債裁定ファンド、ヘッジファンド、保険会社、政府系ファンドが特定の日本ベーシス取引を保有していることを示さない。このため、次の表は参加者像ではなく、証拠の次元を示す。^[Sources: https://www.bis.org/statistics/derstats.htm; https://www.jpx.co.jp/jscc/en/cash/cds/statistics.html.]

| 証拠の次元 | 裏付けられる結論 |
|---|---|
| BIS OTC 集計 | 公表分類の範囲における市場全体の想定元本・グロス市場価値 |
| JSCC 清算統計 | JSCC の公表対象範囲内の清算活動 |
| ファンド・機関の開示 | 開示が商品と期間を特定する場合に限った当該法人のポジション |
| 実行可能な取引証拠 | 特定日の数量、価格、資金調達、取引相手条件 |

### 取引規模

ベーシス取引の規模は、次の制約を受ける。

| 制約 | 実務上の影響 |
|---|---|
| 債券レッグのレポ・資金調達能力 | 現物ロングの規模を制限する |
| プロテクション買いレッグの CDS 市場流動性 | 同じ参照組織と期間における CDS の規模を制限する |
| 取引相手との CSA 条件（証拠金、適格担保） | CDS レッグの資金調達費用に影響する |
| 単一銘柄のクレジット事由に伴うテール・リスク | ヘッジがあっても、クレジット事由発生時にギャップ・リスクが残る |
| 規制資本費用 | 銀行が保有するポジションは RWA・レバレッジを消費する |

ここで用いた公開集計資料から取引規模を順位付けすることはできない。実行可能な規模は、特定の債券、CDS 期間、資金調達条件、取引相手限度、日付によって異なる。

### ロールの動態

CDS 満期を超えてプロテクションを継続する場合、新しい契約が必要となり得る（例えば、5Y CDS がその期間を終えた後に新たな 5Y 契約を締結する）。新しいスプレッド、満期、契約条件、取引費用、インデックスのロールがあれば、それらを機械的なものとして扱わず、全て含める必要がある。
