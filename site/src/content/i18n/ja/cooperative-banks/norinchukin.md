# 農林中央金庫 (Norinchukin Bank)

## Wiki route

This entry sits under [[cooperative-banks/INDEX|cooperative-banks INDEX]]. Read it against [[megabanks/mufg|三菱 UFJ FG (MUFG)]] for peer / contrast context and [[banking/INDEX|banking index]] for the broader system / regulatory boundary.

## TL;DR

農林中央金庫は、JA、JF、JForest とそれらの連合会等を会員とする **協同組織の全国金融機関**で、農林中央金庫法（平成13年法律第93号）を根拠とする民間金融機関である。1923-12-20 に産業組合中央金庫として設立され、1943 年に現名称となった。公式事業区分は「食農」「リテール」「投資」と、それらを支える「コーポレート」。2025-09-30 時点の連結総資産は 83兆2,928億円、会員は 3,167 団体である。 ^[Sources: https://www.nochubank.or.jp/about/profile.html; https://www.nochubank.or.jp/about/business/.]

## 1. 会社概要

**正式名**：農林中央金庫 ^[extracted]
**英名**：The Norinchukin Bank
**略称**：農林中金 / 農中 / Nochu
**設立**：1923（産業組合中央金庫として）^[extracted]
**現法人発足**：1943-03（戦時統合で「農林中央金庫」改称）
**根拠法**：農林中央金庫法（平成13年法律第93号）
**形態**：農林水産業者の協同組合等を会員とする、協同組織の全国金融機関・民間金融機関
**本店**：東京都千代田区大手町1-2-1 Otemachi Oneタワー

### 出資構造（系統団体出資）^[extracted]

- **会員（出資団体）**：JA、JF、JForest とそれらの連合会、その他の農林水産業者の協同組織等のうち同庫に出資する団体
- **会員数**：3,167 団体（2025-09-30）
- **資本金**：4兆8,174億円（2025-09-30）。公式概要は出資を会員から受け入れていると説明する
- 株式会社の株主関係や「上部団体経由」という図式を当てはめず、農林中央金庫法と会員・出資口数の開示で確認する

### 主要拠点

```
農林中央金庫（本店：東京・大手町）
  ├── 国内支店：札幌・仙台・名古屋・大阪・福岡 等
  ├── 海外拠点：
  │     ├── ニューヨーク支店
  │     ├── ロンドン支店
  │     └── シンガポール支店
  ├── 系統団体：
  │     ├── JA バンク（農業協同組合・全国連合会含む系統）
  │     ├── JF マリンバンク（漁業協同組合系統）
  │     └── JForest（森林組合系統）
  └── 子会社・関連会社：
        ├── 農中信託銀行
        ├── 農林中金全共連アセットマネジメント（農林中央金庫と全国共済農業協同組合連合会＝JA 共済連の共同出資による資産運用会社）
        └── その他金融サービス子会社
```

## 2. 事業セグメント・マップ

| 公式事業領域 | 公式説明の要点 | 検証入口 |
|---|---|---|
| 食農ビジネス | 食と農林水産業に関する金融・非金融機能 | 公式「食農ビジネス」 |
| リテールビジネス | JA バンク・JF マリンバンクの一員として金融機能を提供 | 公式「リテールビジネス」 |
| 投資ビジネス | JA バンク・JF マリンバンクの運用の最終的な担い手として収益を追求 | 公式「投資ビジネス」 |
| コーポレート | 三つのビジネスを支える機能と新たな課題への取組み | 公式「コーポレート」 |

Sources: 事業区分と説明は農林中央金庫の現行公式事業紹介に合わせた。「中央銀行」「最後の貸し手」「本業並み」といった法的・収益順位の推定表現は使用しない。 ^[Sources: https://www.nochubank.or.jp/about/business/; https://www.nochubank.or.jp/about/business/investment.html.]

### 系統金融と投資ビジネス

- JA・JF 等が預かった貯金のうち余裕資金が都道府県段階の信農連・信漁連、さらに農林中央金庫へ預けられる流れは公式 FAQ とディスクロージャーで確認する。
- 同庫は投資ビジネスを三つの主軸の一つとして掲げ、国際分散投資と会員への還元を説明している。
- 法定の中央銀行・最後の貸し手ではないため、中央銀行用語は比喩としても使用しない。

### 国際分散投資戦略

- **米国債・社債・MBS** 中心の外貨建て運用
- ニューヨーク・ロンドン・シンガポール 3 拠点で運用・調達
- 資産構成、損益、為替・金利リスクは各期の公式決算・ディスクロージャーで確認する。

### 2024-2025 ポートフォリオ再構築 ^[extracted]

- 2024 年公表方針：米国債等の含み損実現売却（低利回り資産 10 兆円規模の売却計画）+ 資本増強（後配出資 7,360 億円ほか）+ リスク資産再配分
- 出資 JA 等への配当圧縮 → 系統内ガバナンス論点

### 系統金融再編

- JA バンク全国システム（2002〜）の中央プレーヤー
- 都道府県信連（[[cooperative-banks/ja-shinnoren|信用農業協同組合連合会]]）との役割分担再編
- 漁協系統（JF マリンバンク）・森林組合系統（JForest）でも中央機関として資金運用・供給を担う

### 競争ポジション

- **メガバンク（[[megabanks/mufg]] / [[megabanks/smfg]] / [[megabanks/mizuho-fg]]）との比較**：商業銀行業務は限定的、本業は系統金融 + 機関投資
- **生保（[[life-insurers/nippon-life]] / [[life-insurers/dai-ichi-life]]）との比較**：機関投資家としての共通点はあるが、規模比較は同一基準日・資産区分の公式開示で確認する
- **政策金融機関（[[financial-regulators/jfc]] / [[financial-regulators/dbj]]）との比較**：農林水産業向け融資で部分的に競合 / 補完

## 4. 規制・政策

- **主管**：金融庁（FSA）+ **農林水産省**（系統金融部分）— 二重監督が特徴 ^[extracted]
- **根拠法**：農林中央金庫法（平成13年法律第93号）
- **直近政策論点**：
  - 出資 JA への配当・系統還元水準の妥当性
  - 系統金融再編（JA バンク統合・信連との役割分担）
  - 機関投資家としての ESG / 気候リスク開示
