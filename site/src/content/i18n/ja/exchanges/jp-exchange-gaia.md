# 株式会社ガイア — 日本暗号資産交換業者概要

## 1. 法人・株主

- **商号**: 株式会社ガイア
- **設立**: 2007年12月25日（法人組織変更）
- **本店所在地**: 〒550-0002 大阪府大阪市西区江戸堀2-1-1 江戸堀センタービル9F
- **大阪オフィス**: 大阪市西区新町1-28-3 四ツ橋グランスクエア9F
- **東京オフィス**: 東京都千代田区岩本町3-3-3 秋葉原サザンビル5F
- **資本金**: 2,990万円
- **従業員数**: 15名（公表）
- **親会社**: 株式会社ガイアホールディングス（2021年2月設立、暗号資産交換業以外の業務を移管）
- **上場状態**: 非上場

## 2. 牌照・登録状況

- **暗号資産交換業**: 近畿財務局長第00004号（登録日 2021-06-18）
- **JVCEA 第一種会員**: #1034（2021年1月に第二種で加入 → 同年6月に第一種へ種別変更）
- 金融商品取引業・電子決済手段等取引業・資金移動業の登録なし（公表情報の範囲内）
- FSA 一覧では近畿財務局管轄として掲載される。変動する国内業者総数や管轄別順位は固定せず、最新一覧は [[exchanges/fsa-vasp-registration-system|FSA 暗号資産交換業登録制度]] と FSA 原票を参照する

## 3. 取扱通貨

- **取扱銘柄数**: 2026-05-26 の公式 BTM 設置告知で3銘柄を掲載
- **対応銘柄**: BTC（ビットコイン）、ETH（イーサリアム）、ADA（カルダノ）
- **確認範囲**: BTC・ETH・ADA は同日告知の取扱暗号資産欄に基づく。現在の売買方向・入出庫可否は BTM / WEB 両替の現行規約を優先する

## 4. 業務範囲

- **主力サービス**: 暗号資産自動両替機 BTM（Bitcoin Teller Machine）。2022年8月の開始時に同社は「日本国内初」と発表した歴史的主張であり、現在の唯一性や市場順位を示さない（対比は [[exchanges/jp-exchange-coinhub|COINHUB]] の ATM 業態）
- **BTM**: 日本円 ↔ BTC / ETH 購入・売却、ADA 購入のみ対応。1取引最大10万円。
- **WEB 両替サービス**: BTM 不要のオンライン両替（24時間受付、BTC / ETH / ADA の購入・売却対応）
- **インバウンド対応**: 事前の利用者登録をせず ICAO 準拠 IC パスポートで利用する導線を提供。本人確認が不要という意味ではなく、対象取引・上限は現行規約を優先する
- **BTM 機体販売**: パートナー向けに BTM 機体の販売制度あり
- **法定通貨入金チャネル**: 現金紙幣（ATM 投入）または銀行口座振込
- **margin / derivative / staking / NFT / 貸暗号資産**: 2026-07-29 に本輪で確認した公式サービス・規約には提供表示なし

## 5. 市占・取引高

- 2026-07-29 に本輪で列挙したガイア公式・FSA・JVCEA 資料の範囲では、口座数・取引高の開示を確認していない。これは不存在を断定するものではない
- BTM の設置公表は 2022年8月の1台目（大阪）、9月の2台目（東京）、11月の3台目、2026年5月26日の4台目（トラベルハブなんば）と続く。設置数は履歴値であり、全台の同時稼働を保証しない
- 2026年5月1日の一時停止告知は東京タワー内 BTM を対象とし、同社は東京オフィスのサービス継続を明記した。5月26日にはなんばの新 BTM がサービスを開始しており、全 BTM 停止とは扱わない
- 公開サービスは BTM / WEB 両替利用者と IC パスポート導線の訪日客を対象とするが、市場シェア順位は推定しない

## 7. 戦略動向

- BTM 機体のパートナー販売制度を提供し、他事業者との設置展開を公式サービスで案内
- 外国人観光客向けに、事前登録なし・IC パスポート照合による利用導線を提供
- 2026年5月26日にトラベルハブなんばで新 BTM を開始し、設置拠点拡大の方針を公式告知。5月1日の東京タワー機一時停止とは対象を分けて読む
- 2026年7月8日の公式注意喚起は、BTM / WEB 両替を第三者の指示で利用する詐欺・金融犯罪リスクへの利用者保護対応を明示
