# Gate Japan株式会社 — 日本暗号資産交換業者の概要


## ウィキ上の位置づけ

このエントリは [[exchanges/INDEX|exchanges index]] の配下に位置づけられる。隣接する文脈については [[exchanges/fsa-vasp-registration-system|FSA 暗号資産交換業登録制度 — 番号体系・財務局管轄・登録要件]]、より広いシステム境界については [[fintech/japan-financial-regulation|日本金融規制 — トークン・暗号資産・決済に関する法体系]] とあわせて読む。

> FSA 登録番号 関東財務局 第00018号 · JVCEA 会員 #1021 · 登録日 2019-11-27

## 1. 法人・株主

- **商号**：Gate Japan株式会社（英文：Gate Japan K.K.）
- **前身**：株式会社LastRoots → Coin Master株式会社（各商号変更を経て現商号に至る）
- **設立年月日**：2016年6月2日
- **本店所在地**：東京都中央区八重洲二丁目２番１号 東京ミッドタウン八重洲 八重洲セントラルタワー 27F（〒104-0028）
- **グループ関係**：Gate Group は 2024年12月に旧 Coin Master の買収を公表。2026-07-29 の Gate Japan 公式会社ページは Gate グループとの関係を示す一方、具体的な持株比率・中間法人構造は掲載していないため推定しない
- **資本金**：3,984,294,838円（資本準備金含む、2026-07-29 公式会社ページ）
- **従業員数**：24名（正社員・派遣社員・パートナー合計、同日公式会社ページ）

## 2. 牌照・登録状況

- **暗号資産交換業**：関東財務局長 第00018号（登録日 2019-11-27）
- 金融商品取引業・電子決済手段等取引業・資金移動業：2026-07-29 に本輪で確認した Gate Japan 公式会社ページ・JVCEA 会員一覧には登録表示なし
- **JVCEA 会員種類**：第一種会員（会員番号 1021）、暗号資産交換業のみ
- **JCBA 会員種類**：正会員

## 3. 取扱通貨

旧 c0ban 取引所では日本発の独自トークン c0ban（RYO）を取り扱った。2026年4月24日の公式告知は新規口座受付を停止し、同年5月29日をもって c0ban 取引所サービスと RYO 取扱いを終了するとした。2026-07-29 の Gate Japan 公式ページには BTC・ETH 等の価格表示があるが、同ページ自身が Gate グループ全体の参考表示であり Gate Japan の取扱銘柄とは異なると明記する。したがって Gate グループの銘柄数を Gate Japan 個社へ転記せず、現行契約書面・取引画面を優先する。

## 4. 業務範囲

- 2026-07-29 の公式会社ページは **販売所**、**取引所**、**OTC（大口取引）**、**法人向け決済ソリューション**をサービスとして案内する
- 同ページは取引画面ではなく、そのページ上で売買・媒介・勧誘を行わないとの注意書きがある。各サービスの実際の受付状況・取扱銘柄・入出金チャネルは現行契約書面・取引画面で確認する
- 証拠金取引 / デリバティブ / ステーキング / 貸暗号資産：本輪で確認した Gate Japan 個社の公式会社ページ・重要事項説明書には提供表示を確認していない。Gate.com グローバルの機能を Gate Japan へ読み替えない

## 5. 市占・取引高

- 2026-07-29 に本輪で列挙した Gate Japan 公式・FSA・JVCEA 資料の範囲では、Gate Japan 個社の取引高・口座数・市場シェアを確認していない。これは不存在を断定するものではない
- 旧 c0ban 取引所は RYO と円の売買を提供した履歴があるが、公表値なしに競合順位・市場規模を推定しない。Gate Group の日本再参入パターンは [[exchanges/jp-vasp-ma-consolidation-history|JP VASP M&A コンソリデーション史]] および [[exchanges/jp-vasp-parent-company-map|JP VASP 親会社マップ]] 参照
- 公式ページに併記されるグローバル管理資産・利用者・銘柄数は Gate グループ全体の実績であり、Gate Japan 個社の指標として使用しない

## 7. 戦略動向

- **日本向けサービス表示**：2026-07-29 の Gate Japan 公式ページは販売所・取引所・OTC・法人向け決済を案内する。実際の受付状況と取扱銘柄は現行契約書面・取引画面で確認し、グローバル機能を転用しない
- **c0ban 終了**：2026年4月の公式告知に基づき、旧主力 RYO の取扱いと c0ban 取引所サービスを5月29日に終了
- **エンタメ×フィンテック連携**（2026年2月）：国内エンタメ企業コンソーシアムに暗号資産交換業者として参画。Web3 技術を活用した次世代エンタメ産業への協力を表明
- **Gate.com グローバルとの関係**：Gate Japan 公式ページは Gate.com（旧 Gate.io）と別法人であり、海外取引所のアカウント・取引サポートを扱わないと明記。グローバル側は 2024年7月に日本居住者の新規口座開設を停止しており、利用者は法人境界を区別する必要がある
- **WebX 2025**：Gate Group の公式沿革は 2025年8月のタイトルスポンサー参加を掲載するが、これは Gate グループの活動であり Gate Japan 個社の取引実績ではない
