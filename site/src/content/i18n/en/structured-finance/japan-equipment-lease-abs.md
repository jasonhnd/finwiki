# Japan equipment lease ABS — evidence-bound reading

## TL;DR

No stable public transaction document was located that supports the previous JPY 200–400 billion estimate, issuer ranking, equipment-pool shares, lease tenors, residual-value bands, fee range or enhancement comparison. Those values are removed. Lease receivable, ownership, residual-value exposure and end-of-term proceeds must be read from the named contracts and pool.

## 1. Issuer and transaction evidence

[JSDA's securitization-market survey](https://www.jsda.or.jp/en/statistics/securitization-market/) is a market entry point; the following table states the transaction evidence required.

| Field | Required public evidence |
|---|---|
| Legal issuer / trust | Offering or rating document |
| Originator, lessor and servicer | Sale, lease and servicing documents |
| Current affiliation | Dated corporate disclosure |
| Issuance amount | Named series result or defined JSDA table |
| Program history | Dated series list |

## 2. Pool and residual-value exposure

[JCR's methodology library](https://www.jcr.co.jp/en/rrinfo/meth_sf/) supports reviewing the following pool fields, not standard percentages.

| Field | Required named-pool evidence |
|---|---|
| Equipment type | Eligibility and cutoff stratification |
| Lease classification | Contract and applicable accounting classification |
| Ownership and repossession | Title, perfection and enforcement terms |
| Remaining rentals | Schedule, delinquency and lessee concentrations |
| Residual value | Booked assumption, guarantor, sale process, costs and timing |

## 3. Cash-flow priority

[JCR's general structured-finance methodology](https://www.jcr.co.jp/en/pdf/dm28/General_Methodology20210802.pdf) supports the following waterfall checklist.

| Cash-flow field | Required evidence |
|---|---|
| Available collections | Rental, termination, insurance and sale proceeds included |
| Fees and expenses | Named amounts / formulas and priority |
| Note payments | Class-by-class interest and principal order |
| Reserves | Purpose, target, floor and release |
| Residual proceeds | Allocation and shortfall treatment |
| Loss allocation | Write-down and reimbursement order |

## 4. Performance and rating

[The Japan Leasing Association statistics page](https://www.leasing.or.jp/statistics/) and named agency reports support the following evidence controls.

| Claim | Required evidence |
|---|---|
| Industry activity | Defined association statistic and period |
| Pool performance | Dated trustee / servicer report |
| Residual realization | Equipment-level or disclosed cohort results |
| Rating | Named class, action date and criteria version |
| Enhancement | Actual subordination, OC, reserve or guarantee |
| Spread | Named pricing result and benchmark |

## 5. Deferred claims

Issuer market share, annual ABS volume, pool mix, residual-value percentages, fee levels and enhancement ranges remain deferred until a public named deal or defined official statistical table supports them.
