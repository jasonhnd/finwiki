# Auto-loan ABS in Japan — issuer and pool evidence guide

## TL;DR

The prior page asserted repeat-issuer rankings, largest originators, standard GK-TK vehicles, tranche stacks, APR/default behavior and investor categories without named public deals. Those claims are removed. A Japanese auto-loan ABS must be described from its named legal issuer, originator, pool cutoff, servicing, waterfall, enhancement and dated rating / pricing evidence.

## 1. Issuer and program

[JSDA's securitization-market survey](https://www.jsda.or.jp/en/statistics/securitization-market/) is a public market entry point; the following table states the additional evidence required.

| Field | Required public evidence |
|---|---|
| Legal issuer / trust | Offering or rating document |
| Originator and servicer | Sale, trust and servicing documents |
| Current affiliation | Dated corporate disclosure |
| Program / repeat status | Dated series list with defined period |
| Issuance amount | Named result or defined JSDA table |

## 2. Pool

[JCR's methodology library](https://www.jcr.co.jp/en/rrinfo/meth_sf/) supports the following pool checklist.

| Field | Required named-deal evidence |
|---|---|
| Receivable type | Loan, installment sale, lease or floorplan definition |
| Vehicle | Legal form and transaction documents |
| New / used mix | Cutoff-date stratification |
| APR / remaining term | Disclosed weighted measures and ranges |
| Delinquency / loss / recovery | Definitions, cohorts, timing and costs |
| Concentration | Model, dealer, geography and obligor fields |

## 3. Structure and rating

[JCR's general methodology](https://www.jcr.co.jp/en/pdf/dm28/General_Methodology20210802.pdf) supports the following evidence controls.

| Claim | Required evidence |
|---|---|
| Waterfall | Named priority of payments |
| Enhancement | Actual subordination, OC, reserve and support |
| Trigger | Exact metric, threshold, cure and consequence |
| Rating | Named class, agency, date and criteria version |
| Investor / distributor | Public transaction or allocation disclosure |
| Spread | Named pricing result and benchmark |

## 4. Deferred claims

Issuer dominance, annual market size, standard tranche percentages, APR/default ranges, loss timing and investor base remain deferred until supported by public named transactions or defined official statistics.
