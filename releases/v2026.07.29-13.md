# 企業戦略・小売金融の表出典114件を校正

## 日本語

### 公開範囲

- Issue #234 の released-main baseline にある `table_without_provenance` 114 件、32 source paths を bounded scope とする。
- 内訳は `business/` 60 warnings / 16 paths、`corporate-strategy/` 35 warnings / 10 paths、`retail/` 19 warnings / 6 paths。
- 会社・規制当局・取引所の公式資料、法令、適時開示、取引当事者の公表資料を使い、対象表と直近の evidence context を再検証する。
- 32 source entries、ja / en 64 mirrors、三言語 release / operating surfaces、root index / AI discovery surfaces を同じ release unit で同期する。
- `.opinions/**`、`docs/**`、人手判断を待つ Issue #193、後続 Issue #235–#244 の所有範囲は変更しない。

### 主要変更

- 同じ source set が表全体を支える場合だけ scoped lead / footer marker を追加し、証拠が行ごとに異なる表では row-level marker または direct public link を維持した。
- Coinbase の直接上場と発行会社手取金、CZ / Binance の刑事・民事手続と恩赦、SoftBank / Arm と PayPay の上場・支配、Sony Financial Group の部分スピンオフ、東芝の TOB / squeeze-out を、完了・予定・条件付きの状態ごとに分離した。
- みずほ / 楽天の証券・カード・銀行持分、Seven Bank の自己株式取得と連結除外、Seven & i / 伊藤忠の時点別持分、FamilyMart ATM、Lawson の 50/50 所有を、法人・会計・販売チャネルの境界を混同しない形へ校正した。
- 会社分割、株式交換・移転、株式交付、株式分配、合併、持株会社化、グループ通算の各制度について、会社法上の仕組みと税務上の適格 / 非適格判定を分離し、単一比率や対価だけで税務結果を断定する表現を撤回した。
- ja / en 64 mirrors を source-language exact sync または guarded full sync + manual review で更新し、`source_hash`、Markdown shape、wikilink target、URL、provenance marker、日付、金額、比率、否定・条件表現を照合した。

### 検証結果

- `bun run provenance:audit -- --json` は full warnings を 1,837 から 1,723 へ削減し、Issue #234 owned warnings を 114 から 0 にした。full residual は `table_without_provenance` 1,645 と `table_row_without_marker` 78 である。
- mirror candidate audit は 64 files について source hash、source-language body、Markdown heading / table / list / blockquote shape、wikilink target、URL、provenance marker、日付・金額・比率を確認し、blocking problems 0。
- `bun run i18n:status` は ja / en 各 1,442 mirrors が全件 current、stale / orphaned / missing 0、`fidelity: ok` 各 1,442。
- `bun run audit:all -- --as-of 2026-07-29`、`bun run wiki:audit:ci`、`bun run release:write`、full canonical `bun run verify --out _site`、`git diff --check` を通過した。

### 既知の注意点

- provenance audit は read-only / advisory であり、114 warnings の解消は corpus 全体または各 entry の全 prose を一括保証しない。今回の実証範囲は owned tables / rows と修正に必要な直近 context である。
- corpus 全体には 1,723 件の table-related residual warnings が残り、後続の bounded issues が所有する。件数だけを減らす marker 挿入は行わない。
- 所有比率、上場状態、予定取引、税制、商品提供状態は変動するため、公式資料の基準日と `review_by` cadence を維持する。
