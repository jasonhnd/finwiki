# GPT i18n 翻訳バッチ継続・740/740 進捗

## 日本語

### 概要

2026-06-01 JST の GPT/Codex i18n 継続バッチです。前回の zh/en 610 件から、placeholder verify を通過した訳文だけを公開 i18n surface に追加し、累計を zh 740 / en 740 へ進めました。

### 公開範囲

- 対象: `site/src/content/i18n/{zh,en}/`
- 作業 batch: 130 source entries, 260 language outputs
- 記録更新: `README.md`, `CHANGELOG.md`, this release note
- AI discovery / counts: `tools/release.py --write` により同期

### 主要変更

- `bun scripts/prep-parallel.mjs --workers 10 --size 13` で 10 worker 分の job を準備。
- GPT/Codex worker 10 本で `.cache/jobs/w0..w9/` を分担。
- 最初の w8 worker が訳文ファイルを出さなかったため、w8 のみ GPT/Codex retry worker で再処理。
- `bun scripts/commit-translate.mjs` で placeholder verify + unmask を実行。
- 234 language outputs が verify を通過し、26 language outputs は `needs_review` として公開訳文から除外。
- 完了 worker thread は archive 済み。

### 検証結果

- `bun scripts/commit-translate.mjs`: ok=234, needs_review=26, missing=0.
- Cumulative i18n count: zh 740 / en 740.

- `python tools/release.py --check --strict`: passed.

### 既知の注意点

- `needs_review` の 26 language outputs は placeholder mismatch のため公開 i18n に含めていません。
- 残り翻訳と `needs_review` は次回以降の incremental batch で再取得します。

### 次の作業

## English

### Overview

This is the 2026-06-01 JST GPT/Codex i18n continuation batch. Only placeholder-verified translations were added to the public i18n surface, moving cumulative progress from zh/en 610 to zh/en 740.

### Release Scope

- Target: `site/src/content/i18n/{zh,en}/`
- Batch: 130 source entries, 260 language outputs
- Records: `README.md`, `CHANGELOG.md`, and this release note
- AI discovery / counts: synchronized via `tools/release.py --write`

### Major Changes

- Prepared 10 worker directories with `bun scripts/prep-parallel.mjs --workers 10 --size 13`.
- Ran 10 GPT/Codex workers over `.cache/jobs/w0..w9/`.
- Retried only w8 with another GPT/Codex worker after the first w8 worker produced no translation files.
- Collected outputs with placeholder verification and unmasking via `bun scripts/commit-translate.mjs`.
- 234 language outputs passed verification; 26 language outputs were excluded as `needs_review`.
- Completed worker threads were archived.

### Validation Results

- `bun scripts/commit-translate.mjs`: ok=234, needs_review=26, missing=0.
- Cumulative i18n count: zh 740 / en 740.
- `bun run build`: passed, 4147 pages built.
- `python tools/release.py --check --strict`: passed.

### Known Notes

- The 26 `needs_review` language outputs are not included in the public i18n corpus because their placeholder sets did not verify.
- Remaining missing and review outputs will be picked up by later incremental batches.

### Next Work

- Continue the remaining untranslated entries in the next GPT/Codex batch.
- Review repeated `needs_review` patterns after the full translation run and adjust prompt / protect rules where needed.
