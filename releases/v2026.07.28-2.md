# 項目ページの機械可読メタデータ修復

## 日本語

### 公開範囲

- Issue #180 の wiki entry layout、共通 HTML head、frontmatter metadata helper、build 後 metadata audit、canonical verification wiring、focused tests、三言語 README / CHANGELOG / release note。
- wiki entry の事実本文、`ja` / `en` mirror 本文、domain map、公開情報の判断は変更しません。

### 主要変更

- 各 entry language page に同一 route の self-canonical、route-equivalent な `ja` / `en` / `x-default` hreflang を出力し、従来の language homepage alternate を除去しました。非 entry page も現在 route を維持する canonical / hreflang contract に統一しました。
- 各 entry head に per-entry JSON API と raw Markdown の alternate link、schema.org `Article` JSON-LD、frontmatter 由来の `finwiki:domain` / `tags` / `aliases` / `sources` / `confidence` / `status` / `last_updated` / `review_by` meta を追加しました。structured source と HTML-sensitive value も欠落・破損させずに正規化します。
- build 後の全 entry language page を監査する `html:metadata` gate を canonical verification に追加しました。canonical、3 種類の hreflang、resource alternate、frontmatter meta、Article JSON-LD、JSON-LD / meta consistency のいずれかが壊れた場合は fail closed します。

### 検証結果

- `bun run verify --out _site` の full canonical gate は 56 tests / 190 assertions、Astro check 40 files / 0 errors / 0 warnings / 5 hints、dependency vulnerabilities 0 で PASS しました。
- Astro build は 2,969 pages を生成し、全 2,884 entry language pages の metadata audit は issues 0、duplicate ID 0、Pagefind 2,968 pages、assembly 6,258 Astro files + 3,065 raw files、13 required routes で PASS しました。
- generated route audit は 6,029 unique internal URLs を確認し、release docs、strict release、docs、surface drift、i18n、index count、wiki link、`git diff --check` を含む全 gate が PASS しました。

### 既知の注意点

- `x-default` は日本語 entry route を指し、`ja` / `en` alternate は必ず同じ domain / slug を維持します。
- commit、push、remote verification、PR / CI、Vercel deployment、GitHub Release はまだ実施・確認していません。

### 次の作業

- real pre-push を実行し、branch を commit / push して remote HEAD を確認します。
- pass evidence を Issue #180 と `pre` 向け PR に記録し、maintainer review を待ちます。self-merge / self-close は行わず、`main` publish と GitHub Release は承認済み promotion 時だけ行います。

## English

### Release Scope

- Issue #180 wiki-entry layout, shared HTML head, frontmatter metadata helper, post-build metadata audit, canonical-verification wiring, focused tests, and the trilingual README / CHANGELOG / release note.
- Factual wiki-entry bodies, `ja` / `en` mirror bodies, the domain map, and public-information judgments are unchanged.

### Major Changes

- Every entry-language page now emits a same-route self-canonical and route-equivalent `ja` / `en` / `x-default` hreflang links, replacing the previous language-homepage alternates. Non-entry pages also preserve their current route under the shared canonical/hreflang contract.
- Every entry head now exposes per-entry JSON API and raw Markdown alternate links, schema.org `Article` JSON-LD, and frontmatter-backed `finwiki:domain`, `tags`, `aliases`, `sources`, `confidence`, `status`, `last_updated`, and `review_by` metadata. Structured sources and HTML-sensitive values are normalized without loss or corruption.
- Added an `html:metadata` gate that audits every built entry-language page as part of canonical verification. It fails closed on any broken canonical, three-way hreflang set, resource alternate, frontmatter meta, Article JSON-LD, or JSON-LD/meta consistency check.

### Validation Results

- The full canonical `bun run verify --out _site` gate passed with 56 tests / 190 assertions, Astro check across 40 files with 0 errors / 0 warnings / 5 hints, and zero dependency vulnerabilities.
- The Astro build produced 2,969 pages; the metadata audit passed all 2,884 entry-language pages with zero issues, with zero duplicate IDs, 2,968 Pagefind pages, assembly of 6,258 Astro files plus 3,065 raw files, and all 13 required routes.
- The generated-route audit resolved all 6,029 unique internal URLs, and every release-doc, strict-release, docs, surface-drift, i18n, index-count, wiki-link, and `git diff --check` gate passed.

### Known Notes

- `x-default` points to the Japanese entry route, while `ja` and `en` alternates always preserve the same domain and slug.
- Commit, push, remote verification, PR/CI, Vercel deployment, and the GitHub Release have not yet been performed or confirmed.
