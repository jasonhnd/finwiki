# 銀行・協同組織金融の表出典146件を校正

## 日本語

### 公開範囲

- Issue #233 の released-main baseline にある `table_without_provenance` / `table_row_without_marker` 146 件、69 source paths を bounded scope とする。
- 内訳は `banking/` 103 warnings / 31 paths、`cooperative-banks/` 43 warnings / 38 paths。
- 法令、金融庁・日本銀行の公開資料、預金保険制度資料、各法人・業界団体の公式概要、沿革、開示資料を用い、対象表と直近の evidence context を再検証する。
- 69 source entries、ja / en 138 mirrors、三言語 release / operating surfaces、root index / AI discovery surfaces を同じ release unit で同期する。
- `.opinions/**`、`docs/**`、人手判断を待つ Issue #193、後続 Issue #234–#244 の所有範囲は変更しない。

### 主要変更

- 同じ source set が表全体を支える場合だけ scoped lead / footer marker を追加し、行ごとに根拠が異なる場合は row-level marker または direct public link を維持した。遠い source inventory や generic marker を table coverage とみなしていない。
- banking lane では、普通銀行、信託銀行、ネット銀行、外国銀行支店、信用金庫、信用組合、労働金庫、JA / JF 系統の法令・監督・預金保険・日銀取引経路を分離した。未確認の規模順位、営業優位性、取引先関係、固定された商品条件を確定事実から除き、基準日と一次資料を明示した。
- cooperative-banks lane では、現行法人、前身・合併、中央機関、業界団体、共同 IT、資産運用会社を法人単位で再識別した。`shinkin-network-services` の架空会社・子会社説明を一般社団法人しんきん共同センターへ修正し、名古屋・北九州・札幌の歴史的 slug を現行法人または後継法人の識別ページとして校正した。
- 農林中央金庫について、本店を大手町、現行法を平成13年法律第93号、法的形態を協同組織の全国金融機関・民間金融機関へ統一した。「特殊法人」「中央銀行」「最後の貸し手」、旧本店、未検証の規模順位を撤回し、JA / JF / JForest の中央機関としての範囲を公式資料に限定した。
- ja / en 138 mirrors を source-language exact sync または guarded line-level sync + manual review で更新した。`source_hash`、Markdown shape、wikilink target、URL、provenance marker、金額・比率を照合し、英語の `¥10 million` を日本語で `10 万円`、`¥2 billion` を `2 億円`とする旧数量級誤訳も、それぞれ `1,000 万円`、`20 億円`へ修正した。

### 検証結果

- `bun run provenance:audit -- --json` は full warnings を 1,983 から 1,837 へ削減し、Issue #233 owned warnings を 146 から 0 にした。`banking/` と `cooperative-banks/` はともに owned residual 0、full residual は `table_without_provenance` 1,759 と `table_row_without_marker` 78 である。
- mirror candidate audit は 138 files について source hash、source-language body、Markdown shape、wikilink target、URL、provenance marker、円金額の意味的一致を確認し、blocking problems 0。`bun run i18n:status` は ja / en 各 1,442 mirrors が全件 current、stale / orphaned / missing 0、`fidelity: ok` 各 1,442 となった。
- `bun run audit:all -- --as-of 2026-07-29`、`bun run wiki:audit:ci`、`bun run release:write`、full canonical `bun run verify --out _site`、`git diff --check` を通過した。

### 既知の注意点

- provenance audit は read-only / advisory であり、146 warnings の解消は corpus 全体または各 entry の全 prose を一括保証しない。今回の実証範囲は owned tables / rows と、修正に必要な直近の法人・法令・数量 context である。
- corpus 全体には 1,837 件の table-related residual warnings が残り、後続の bounded issues が所有する。件数だけを減らすための marker 挿入は行わない。
- 法令一覧、金融機関数、会員数、拠点、役員、資産・預金・貸出、商品条件は変動するため、公式資料の再確認と `review_by` cadence を維持する。

### Major Changes

- Added a scoped lead / footer marker only where one source set supports the full table, retaining row-level markers or direct public links where evidence differs by row. A distant source inventory or generic marker is not treated as table coverage.
- Separated the statutes, supervision, deposit-insurance routes, and Bank of Japan transaction routes for ordinary banks, trust banks, net banks, foreign-bank branches, shinkin banks, credit cooperatives, rokin, and the JA / JF systems. Removed unverified scale rankings, operating superiority, counterparty relationships, and fixed product terms from established-fact wording while preserving source dates.
- Reidentified current entities, predecessors and mergers, central institutions, industry bodies, shared IT, and asset managers in the cooperative-banks lane. The fictitious-company and subsidiary description at `shinkin-network-services` now identifies the General Incorporated Association Shinkin Kyodo Center, while the historical Nagoya, Kitakyushu, and Sapporo slugs now route to verified current or successor entities.
- Aligned the Norinchukin Bank's head office to Otemachi, governing law to Act No. 93 of 2001, and legal form to a national cooperative financial institution and private financial institution. Withdrew the “special corporation,” “central bank,” “lender of last resort,” old-head-office, and unsupported size-ranking claims and limited its JA / JF / JForest central-institution role to official disclosures.
- Updated 138 ja/en mirrors through exact source-language sync or guarded line-level sync plus manual review. Checked `source_hash`, Markdown shape, wikilink targets, URLs, provenance markers, amounts, and ratios; also corrected legacy order-of-magnitude errors that had rendered English `¥10 million` as Japanese `10 万円` and `¥2 billion` as `2 億円`, restoring `1,000 万円` and `20 億円`.

### Validation Results

- `bun run audit:all -- --as-of 2026-07-29`, `bun run wiki:audit:ci`, `bun run release:write`, full canonical `bun run verify --out _site`, and `git diff --check` passed.

- Statutory lists, institution counts, membership, offices, officers, assets, deposits, loans, and product terms can change; official-source rechecks and the `review_by` cadence remain required.
