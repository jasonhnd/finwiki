# 監査成果物の公開境界分離

## 日本語

### 公開範囲

- Issue #178 の truthfulness audit output boundary、corpus / discovery / API / site / publish exclusions、shareable summary privacy、workflow、focused tests、三言語 README / CHANGELOG / release note と生成 public snapshot。
- audit threshold policy と wiki entry の事実本文は変更しません。

### 主要変更

- audit の既定出力を repository 外の OS temporary directory とし、repository 内の明示出力は ignored `audit-artifacts/` またはその子 directory だけに制約しました。
- `summary.json` / `summary.md` から repository root と artifact absolute path を削除し、GitHub Actions は `$RUNNER_TEMP` の成果物だけを step summary / workflow artifact として公開します。
- shared Markdown walker、wiki-link audit、release / discovery / API、surface drift、static publisher の全境界で audit artifact を排除し、publisher は Astro output に同 directory が現れた場合も fail します。

### 検証結果

- 修正前は local audit 後に strict release が 1,490 entries / issues 1 で fail することを再現しました。
- focused tests は 10 tests / 64 assertions を通過し、audit 前後の fixed-timestamp discovery / API / sitemap output が byte-identical、summary / public output に artifact path がないことを確認しました。
- ignored artifact が存在する実 repository でも strict release は修正前 baseline の 1,576 Markdown、1,489 entries / issues 0 を維持し、surface drift は API 1,482 entries と docs / audit / local-path leakage 0 で PASS。release record 追加後の canonical gate は 1,577 Markdown、39 files / 0 type errors / 5 hints、38 tests / 144 assertions、Astro 2,969 pages、Pagefind 2,968 pages、assembly 6,258 + 3,063 files、13 required routes を通過しました。

### 既知の注意点

- truthfulness threshold は引き続き advisory です。CLI stdout は operator 向けに実際の output directory を表示しますが、shareable summary には保持しません。
- branch は #184、#185、#186、#177 の dependency chain に積み重なっており、前提が `pre` に入るまでは重複 PR を開きません。

### 次の作業

- canonical verification と real pre-push を完了して Issue #178 に evidence を記録し、dependency merge 後に最新 `pre` へ replay して fresh PR review / CI を待ちます。self-merge / self-close は行いません。
