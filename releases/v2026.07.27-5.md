## English

### Release Scope

- Issue #178 truthfulness-audit output boundary, corpus/discovery/API/site/publish exclusions, shareable-summary privacy, workflow, focused tests, trilingual README / CHANGELOG / release note, and generated public snapshot.
- Audit threshold policy and factual wiki-entry bodies are unchanged.

### Major Changes

- Default audit output now stays outside the repository under the OS temporary directory; explicit in-repository output is restricted to ignored `audit-artifacts/` or descendants.
- Removed repository-root and artifact absolute paths from `summary.json` / `summary.md`; GitHub Actions publishes only the `$RUNNER_TEMP` result to the step summary and workflow artifact.
- Excluded audit artifacts across the shared Markdown walker, wiki-link audit, release/discovery/API paths, surface drift, and static publishing. Publishing also fails if that directory appears in Astro output.

### Validation Results

- Reproduced the pre-fix failure where a local audit changed strict release to 1,490 entries / one issue.
- Focused suites passed 10 tests / 64 assertions and proved fixed-timestamp discovery/API/sitemap output is byte-identical before and after auditing, with no artifact path in summaries or public output.
- With ignored artifacts present in the real repository, strict release preserved the pre-change baseline of 1,576 Markdown files and 1,489 entries / zero issues; surface drift passed with 1,482 API entries and zero docs/audit/local-path leaks. After adding the release record, the canonical gate passed at 1,577 Markdown files, 39 checked files / zero type errors / five hints, 38 tests / 144 assertions, 2,969 Astro pages, 2,968 Pagefind pages, assembly of 6,258 + 3,063 files, and all 13 required routes.

- This branch is stacked after the #184, #185, #186, and #177 dependency chain; no duplicate PR will open before prerequisites enter `pre`.
