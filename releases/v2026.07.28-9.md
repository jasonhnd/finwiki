# 検証基盤統合と公開リリース再開

## 日本語

### 公開範囲

- 2026-07-01 の公開 main snapshot 以後に `pre` で検証された Issues #177-#191、#194、#198 の統合成果を、`v2026.07.28-9` catch-up release として公開する。
- 対象は三言語 release governance、static publish boundary、dependency / verification pipeline、audit artifact isolation、AI discovery、i18n integrity、site metadata / route QA、truthfulness history、active docs と canonical-anchor contract。
- wiki corpus の新規 fact batch、`.opinions/**` の policy decision、advisory truthfulness queue の content remediation は含まない。

### 主要変更

- Bun 1.3.14 と frozen lockfile を固定し、local pre-push、PR、Vercel、GitHub Pages を一つの `bun run verify` pipeline に統一した。Astro 7.1.3、実 typecheck、82-test suite、production dependency audit を release gate にした。
- final static artifact を manifest allowlist に限定し、docs / tooling / hidden source / audit artifacts の混入、missing route、wrong-origin discovery URL、canonical surface drift を fail-close する。
- translation placeholder order と failed-output quarantine、40-domain shared corpus discovery、entry HTML metadata / route-level hreflang、current JST review boundary、history-aware scheduled audit を修復した。
- root schema / architecture / policy を現行 `canonical_anchor` contract に統一し、11 active developer docs を `docs/README.md` から到達可能にした。
- release state registry を追加し、22 staging notes を本 catch-up release に明示的に包含した。欠落していた `v2026.05.29` repository note を既存 Release body から復元し、2026-07-01 cutover 前の 6,127 行 timeline を immutable Git history へ archive-link した。

### 検証結果

- full canonical `bun run verify --out _site` は 82 tests / 272 assertions、Astro check 44 files / 0 errors / 0 warnings / 0 hints、Astro 2,969 pages、entry metadata 2,884 / issues 0、Pagefind 2,968 pages、assembly 6,258 Astro files + 3,076 raw public files、13 required routes、final HTML audit 5,864 routes、generated URL audit 6,040 unique URLs、production vulnerability 0 で PASS。
- release docs は 19 files / 17 strict notes / 76 grandfathered notes、wiki audit は 1,489 entries / issues 0 / canonical drift 0、generated-surface drift は API 1,482 entries / fixed-timestamp byte identity / leakage 0 を確認した。publish は current HEAD の real pre-push と PR Required Verification / Dependency Audit / Vercel が green の場合に限る。

### 既知の注意点

- `.opinions/**` 685 tracked files の public boundary は Issue #193 の human policy decision 待ちであり、本 release は移動・削除・再分類しない。
- Issue #192 の truthfulness review queues は advisory であり、公開 source を使う bounded child issues に分割して処理する。本 release は queue を解消済みとは扱わない。
- `Required verification` workflow はこの promotion で初めて `main` に入るため、main protection は production deploy 成功後に直ちに有効化し、以後の direct push を禁止する。

### 次の作業

- `pre → main` promotion の exact merge SHA を確認し、Deploy FinWiki を完走させ、代表 public URL を検証する。
- 同じ main merge commit に tag `v2026.07.28-9` と本 note の GitHub Release を作成する。
- `main` に PR requirement、current `Required verification`、admin enforcement、force-push / deletion prohibition を設定し、Issues #184 / #188 に証拠を記録する。

## English

### Release Scope

- Publish the integrated results validated on `pre` for Issues #177-#191, #194 and #198 since the 2026-07-01 public main snapshot as the `v2026.07.28-9` catch-up Release.
- Scope includes trilingual release governance, the static-publish boundary, dependency and verification pipelines, audit-artifact isolation, AI discovery, i18n integrity, site metadata/route QA, truthfulness history, active docs and the canonical-anchor contract.
- New wiki-fact batches, the `.opinions/**` policy decision and content remediation for advisory truthfulness queues are excluded.

### Major Changes

- Pinned Bun 1.3.14 with frozen-lockfile installs and unified local pre-push, PR, Vercel and GitHub Pages on one `bun run verify` pipeline. Astro 7.1.3, real typechecking, an 82-test suite and production dependency auditing are release gates.
- Restricted the final static artifact to a manifest allowlist and fail-closed on docs/tooling/hidden-source/audit-artifact leakage, missing routes, wrong-origin discovery URLs and canonical-surface drift.
- Repaired translation placeholder ordering and failed-output quarantine, shared corpus discovery across 40 domains, entry HTML metadata and route-level hreflang, the current-JST review boundary and history-aware scheduled audits.
- Aligned the root schema, architecture and policy docs on the current `canonical_anchor` contract and made all 11 previously unlinked active developer docs reachable from `docs/README.md`.
- Added a release-state registry that intentionally incorporates 22 staging notes into this catch-up Release. Restored the missing repository note for `v2026.05.29` from its existing Release body and archive-linked the 6,127-line pre-2026-07-01 timeline in immutable Git history.

### Validation Results

- Full canonical `bun run verify --out _site` passed with 82 tests / 272 assertions; Astro check across 44 files with 0 errors / 0 warnings / 0 hints; 2,969 Astro pages; 2,884 entry-metadata pages with zero issues; 2,968 Pagefind pages; assembly of 6,258 Astro files plus 3,076 raw public files; all 13 required routes; a final HTML audit across 5,864 routes; a generated URL audit across 6,040 unique URLs; and zero production vulnerabilities.
- Release docs reported 19 files / 17 strict notes / 76 grandfathered notes; the wiki audit reported 1,489 entries / zero issues / zero canonical drift; and generated-surface drift confirmed 1,482 API entries, fixed-timestamp byte identity, and zero leakage. Publication additionally requires green real pre-push and PR Required Verification / Dependency Audit / Vercel checks on the current head.

- The public boundary for 685 tracked `.opinions/**` files remains a human policy decision in Issue #193; this Release does not move, delete or reclassify them.

- The `Required verification` workflow first reaches `main` through this promotion, so main protection is enabled immediately after the production deploy and blocks future direct pushes.
