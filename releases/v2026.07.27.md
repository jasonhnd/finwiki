# 三言語リリース文書契約の復元

## 日本語

### 公開範囲

- Issue #187 の governance / release-tooling 修復。README、CHANGELOG、active developer docs、release note、release gate、AI discovery metadata を対象とする。人間向けサイトの locale と wiki entry の事実本文は対象外。

### 主要変更

- `tools/release_documentation_audit.ts` と 10 件の focused test を追加し、README / CHANGELOG / post-contract release note の言語順序、日本語のみの title、各言語の必須 5 節を検証する。
- `release.ts --check/--write` の mutation 前に同じ gate を統合し、三言語 CHANGELOG scaffold、言語別 README metric 同期、`--write --release-note "<日本語タイトル>"` による検証済み三言語 draft 生成を追加した。
- README、CHANGELOG、要求・仕様・QA・runbook を日本語→英語→中国語へ揃え、中国語 / 三言語 governance text を discovery metadata から除外していた filter を撤去した。

### 検証結果

- `bun test tools/release_documentation_audit.test.ts` は 10 tests PASS。tooling bundle、`bun run release:docs`、strict release、docs / stale、generated-surface、AI route、i18n（ja/en 各 1442 current、stale / orphaned / missing 0）、wiki / canonical（issues=0 / drift=0）、index count、Astro build（2969 pages）、Pagefind（ja/en 2968 pages）、HTML duplicate-ID（0）、diff hygiene はすべて PASS。
- 実際の release draft generation は PASS。日英混在 title の integration negative check は draft を落盤せず EXIT=2。

### 既知の注意点

- 2026-07-27 より前の 75 release notes は公開履歴として grandfather し、自動三言語 gate の対象外にする。過去の CHANGELOG / tag / GitHub Release 欠落復元は Issue #188 で扱う。
- 三言語 release documentation は中国語 site route / mirror の復活を意味しない。公開人間向け route は `ja` / `en` のまま。GitHub Release は `main` publish 時まで作成しない。

### 次の作業

- 最終 gate と generated diff を review し、`pre` 向け PR を開いて maintainer review を待つ。merge 後に依存する Issue #177 の静的 publish 修復を開始する。

## English

### Release Scope

- Governance and release-tooling repair for Issue #187, covering README, CHANGELOG, active developer docs, release notes, the release gate, and AI discovery metadata. Human-site locales and factual wiki-entry bodies are out of scope.
