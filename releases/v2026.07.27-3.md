- `bun run check` は 39 files、0 errors、0 warnings、5 hints で exit 0。`bun test` は 3 files / 25 tests、fail 0 でした。
- `bun tools/vercel_build.ts` は link audit、strict release check、dependency audit、publish tests 7/7、Astro build（2,969 pages）、duplicate ID check（0）、Pagefind（2,968 pages）と assembly（Astro 6,258 files + raw 3,061 files）を通過しました。
- release-document、docs、generated-surface、txt-route、i18n、index-count、wiki-link と diff gate も PASS しました。
