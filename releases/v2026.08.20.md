# 読者経路の組版を公開

## 日本語

### 公開範囲

- `pre` にある UIUX 読者経路を `main` へ公開する。対象は #300、#301、#304、#306、#308、#310、#312。
- wiki 本文の新規追加や entity batch は含めない。

### 主要変更

- 現行シーズンを UIUX 本線 / Content 保守に切り替える。
- ホーム第一画面は一文、検索、編集した「まず読む」。カタログは fold 下。
- 領域詳細は番号付きのまず読むと一欄の項目一覧。メガバンクは MUFG / SMFG / みずほ FG。
- 条目は H1 → 一行の根拠 → 要約。ウィキ位置づけとタグは本文の後。
- 日文の語中折行をやめ、領域総表・全項目・ルート・検索も同じ組版にする。

### 検証結果

- work→`pre` の Required verification PASS。
- ja 375 / 1440 でホーム、メガバンク、MUFG、領域総表、全項目、ルートを目視。
- `bun tools/release.ts --check --strict`、`astro check`、HTML route audit PASS。

### 既知の注意点

- 要約本文の日英混排は corpus のまま。本 release は UI 組版のみ。
- typed `entity_edges` 関係パネルは今シーズンの対象外。

### 次の作業

- production deploy 完了を確認する。
- GitHub Issues が空のあいだ、Content は監査が閾値を超えたときだけ再開する。
