# 公開ホームページ内容地図更新 2026-05-22

## 日本語

### 概要

FinWiki の公開ホームページ `index.html` を、公開面ルール中心の案内から、wiki 全体の現在の収録内容を説明する内容地図へ更新しました。

### 対象範囲

- `index.html`
- `README.md`
- `AGENTS.md`
- `CHANGELOG.md`
- `wiki-link-improvement-plan.md`
- `releases/v2026.05.22-2.md`

### 主要変更

- 日本語、英語、中国語の homepage から `個人情報の排除` / `No Private/Local Data` / `严禁私密数据` のカードを削除。
- homepage の status を `832 entries / 20 domains` に更新。
- homepage の main domains を、日本金融機関、金融ライセンス、決済・fintech、取引所・VASP、銀行・政策金融、金融・証券・資本市場、市場インフラ、保険・産業・loyalty、systems / security / agent economy まで拡張。
- 今後 wiki 内容、索引、領域数、公開 snapshot を更新するたびに root `index.html` も内容地図として更新する rule を `README.md` と `AGENTS.md` に追加。
