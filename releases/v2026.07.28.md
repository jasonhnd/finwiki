# 翻訳保護と公開隔離の強化

## 日本語

### 公開範囲

- Issue #181 の placeholder / Markdown URL 保護、順序検証、失敗訳の local review queue 隔離、formal mirror の atomic commit、Astro の publishability guard、focused tests、三言語 CHANGELOG / release note。
- source corpus と既存 `site/src/content/i18n/{ja,en}/` mirror 本文は変更しません。

### 主要変更

- placeholder を sort 済み集合ではなく完全な出現順で比較し、reorder、duplicate、missing、unknown token を fail closed で検出します。
- wikilink に加え、inline / reference / autolink / bare Markdown URL を mask し、URL 内の数字や日付を含む全 destination を一体として保護します。
- 検証失敗時は formal mirror を作成・上書きせず、candidate、masked source、mask values、diagnostics を Git ignored の `site/.cache/translation-review/` へ隔離します。direct translation の title / body は一つの atomic update です。
- Astro site、localized-title index、一覧、translation count は `fidelity: ok` の mirror だけを使用し、`needs_review` や fidelity 不明の mirror は source fallback とします。

### 検証結果

- focused translation suite: 12 tests / 47 assertions PASS。
- root suite: 54 tests / 197 assertions PASS。
- Astro check: 41 files、0 errors、0 warnings、5 既知 hints。Astro build: 2,969 pages PASS。
- i18n status: ja / en 各 1,442 current、stale / orphaned / missing 0、fidelity ok 1,442。

### 既知の注意点

- review queue は local ignored artifact であり、corpus、AI discovery、API、site、publish artifact には入りません。
- 現在の committed mirror に `needs_review` は 0 件です。5 Astro hints は Issue #198 の既存 scope です。

### 次の作業

- full canonical verification、PR / CI、preview deployment の evidence を Issue #181 に記録します。
- `main` promotion と GitHub Release は承認済み release flow でのみ行います。

## English
