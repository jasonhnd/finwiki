# 反復事実整合性監査の精度改善

## 日本語

### 公開範囲

- Issue #218 の 2026-07-29 factual-consistency snapshot にある 46 `needs_review` rows / 8 repeated groups を、公開一次情報と報告された正確な行で再検証する。
- directional relationship extraction、labelled numeric extraction、focused tests、active quality contract、3 source entries と現在の ja / en mirrors、三言語 README / CHANGELOG / release state、generated discovery surfaces を対象とする。
- `.opinions/**` の公開境界と別 issue の freshness / provenance / candidate queues は変更しない。

### 主要変更

- 44 relationship rows は、行の最初の link を parent とした detector false positives と判定した。current parent は explicit parent / shareholder label、`subsidiary of` / `owned by`、日本語の `の子会社` から方向付きで抽出し、self / peer / child / historical link と ambiguous tie を除外する。
- 2 capital rows のうち、ownership 100% を capital と誤認した 1 row は metric label に最も近い amount だけを結び付けて解消した。残る実差異は au じぶん銀行の資本金を公式 2026-03-24 増資後の 1,190 億円へ更新した。
- exact source-line review で追加検出した GMO あおぞらネット銀行の議決権構造を、2026-02-20 時点のあおぞら銀行 85.12% に修正した。
- Sony Life の governance を、Sony FG による直接 100% 所有、2025-09-29 再上場、2025-10-01 の 83.60% パーシャルスピンオフ後に Sony Group が親会社でなくなった現行構造へ更新した。
- 大和ネクスト銀行、UI銀行、トヨタファイナンシャルサービス、ソニー銀行の current-parent facts は公式情報と一致し、本文変更不要と確認した。

### 検証結果

- focused consistency suite は 2 tests / 3 assertions で PASS。日本語 / 英語の genuine parent difference と capital difference の検出を維持した。

- `bun run i18n:status` は ja / en 各 1,442 mirrors、current 1,442、stale / orphaned / missing 0。
- full canonical `bun run verify --out _site` は PASS。release docs 22 files / 20 strict notes / 76 grandfathered notes、wiki 1,489 entries / issues 0 / canonical drift 0、generated API 1,482 entries / fixed-timestamp byte identity / leakage 0、production vulnerability 0、Astro check 44 files / 0 errors / 0 warnings / 0 hints、89 tests / 310 assertions、Astro 2,969 pages、entry metadata 2,884 / issues 0、Pagefind 2,968 pages、assembly 6,258 Astro files + 3,079 raw files、13 required routes、final HTML 5,864 routes、generated URL 6,043 unique internal URLs、`git diff --check` を確認した。

### 既知の注意点

- factual-consistency report は advisory のままで、自動修正や hard release gate を追加しない。
- current-parent detector は方向が曖昧な prose を推測しない。明示的な関係 label がない文章は public-source review の対象になり得る。
- 公開企業の資本・所有構造は変化し得るため、各 entry の `review_by` と一次情報による再校正を継続する。

### Release Scope

- Recheck the 46 `needs_review` rows / eight repeated groups in Issue #218's 2026-07-29 factual-consistency snapshot against public primary sources and the exact reported lines.
- Scope covers directional relationship extraction, labelled numeric extraction, focused tests, the active quality contract, three source entries and current ja/en mirrors, trilingual README/CHANGELOG/release state, and generated discovery surfaces.

### Major Changes

- Classified all 44 relationship rows as detector false positives caused by choosing the first link on a line as the parent. Current parents now require directional context from explicit parent/shareholder labels, `subsidiary of` / `owned by`, or Japanese `の子会社`; self, peer, child, historical, and ambiguously tied links are excluded.
