# 表単位の出典監査校正

## 日本語

### 公開範囲

- Issue #219 の `table_row_without_marker` queue を、表単位の近接 source contract で再校正する。
- `tools/provenance_completeness_audit.ts`、focused fixtures、active quality / test documentation、三言語 README / CHANGELOG / release state、release generator が同期する公開 surface を対象とする。
- wiki corpus 本文、ja / en mirrors、`.opinions/**`、別 reason の provenance content queue は変更しない。

### 主要変更

- Markdown table を header / factual rows / section context の単位で解析し、各行の `^[marker]` / direct public HTTP(S) link と、明示的な table lead、caption、footer、bounded section source block を区別するようにした。
- same-section の table-level evidence は、最大 3 logical blocks / 12 physical lines に限定した。generic な近接 marker、隣接 row の marker、遠い `## Sources` は table 全体へ伝播しない。
- 完全に未出典の factual table は行ごとの重複 warning ではなく 1 件の `table_without_provenance`、source が混在する table は未 cover 行だけを `table_row_without_marker` として報告する。
- 大きい `--json` report を awaited stdout で完全出力し、pipe 経由でも parse 可能にした。
- release base の 6,313 row warnings を 2,175 table warnings + 105 mixed-row warnings = 2,280 residuals へ校正した。5,656 old rows は table-level task へ統合、599 rows は scoped evidence により detector false positive、58 rows は維持、隣接 marker spillover に隠れていた 47 rows は新たに可視化した。
- 39 domains / 1,064 paths の全 residual を 14 bounded content issues #231-#244 へ exact routing した。

### 検証結果

- focused provenance suite は 8 tests / 13 assertions で PASS した。
- `bun run provenance:audit -- --json | jq` は complete JSON を parse し、全 report は warning 2,336 件（table-related 2,280 + non-table low-marker 56）、`needs_review=0` となった。
- `bun run audit:all -- --as-of 2026-07-29` は factual consistency / provenance needs-review / freshness の全 threshold を `not_tripped` または history 不足の `monitor` とし、blocking count 0 で完走した。
- full canonical `bun run verify --out _site` は PASS。release docs 24 files / 22 strict notes / 76 grandfathered notes、wiki 1,489 entries / issues 0 / canonical drift 0、generated API 1,482 entries / fixed-timestamp byte identity / leakage 0、ja / en mirrors 各 1,442 current、production vulnerability 0、Astro check 44 files / 0 errors / 0 warnings / 0 hints、97 tests / 323 assertions、Astro 2,969 pages、entry metadata 2,884 / issues 0、Pagefind 2,968 pages、assembly 6,258 Astro files + 3,081 raw files、13 required routes、final HTML 2,969 files / 5,864 routes / 283,184 hrefs、generated URL 6,045 unique internal URLs、`git diff --check` を確認した。

### 既知の注意点

- provenance audit は引き続き read-only / advisory であり、source marker の自動挿入や hard release gate は追加しない。
- 2,280 residuals は「誤り」と断定した件数ではなく、public source scope を人手で確認すべき bounded queue である。
- #221-#224 の non-table low-marker batches と #193 の human governance decision は別 scope のまま維持する。

### 次の作業

## English

### Release Scope

- Recalibrate Issue #219's `table_row_without_marker` queue with a table-aware source-proximity contract.
- Scope covers `tools/provenance_completeness_audit.ts`, focused fixtures, active quality/test documentation, trilingual README/CHANGELOG/release state, and public surfaces synchronized by the release generator.
- Wiki corpus bodies, ja/en mirrors, `.opinions/**`, and provenance content queues with other reason codes remain unchanged.

### Major Changes

- Parse Markdown tables as headers, factual rows, and section context, distinguishing row-level `^[marker]` / direct public HTTP(S) links from explicit table leads, captions, footers, and bounded section source blocks.
- Limit same-section table evidence to three logical blocks and twelve physical lines. A generic nearby marker, a marker in an adjacent row, or distant `## Sources` no longer spreads across a table.
- Emit one `table_without_provenance` row for a wholly unsupported factual table instead of duplicate per-row warnings; mixed-source tables retain `table_row_without_marker` only for uncovered rows.
- Await stdout when emitting the large `--json` report so downstream pipes receive complete parseable JSON.
- Recalibrated the release-base 6,313 row warnings to 2,175 table warnings plus 105 mixed-row warnings, for 2,280 residuals. Of the old rows, 5,656 consolidate into table tasks, 599 are scoped-evidence detector false positives, and 58 remain; 47 rows previously hidden by adjacent-marker spillover are newly visible.
- Routed all residuals across 39 domains / 1,064 paths into 14 bounded content issues #231-#244.

### Validation Results

- The focused provenance suite passed with 8 tests / 13 assertions.
- `bun run provenance:audit -- --json | jq` parsed the complete report: 2,336 advisory warnings in total (2,280 table-related plus 56 non-table low-marker), with `needs_review=0`.
- `bun run audit:all -- --as-of 2026-07-29` completed with every factual-consistency, provenance-needs-review, and freshness threshold either `not_tripped` or `monitor` for insufficient history, with zero blocking rows.
- Full canonical `bun run verify --out _site` passed: 24 release-doc files / 22 strict notes / 76 grandfathered notes; 1,489 wiki entries / zero issues / zero canonical drift; 1,482 generated API entries / fixed-timestamp byte identity / zero leakage; 1,442 current ja mirrors and 1,442 current en mirrors; zero production vulnerabilities; Astro check across 44 files with 0 errors / 0 warnings / 0 hints; 97 tests / 323 assertions; 2,969 Astro pages; 2,884 entry-metadata pages with zero issues; 2,968 Pagefind pages; assembly of 6,258 Astro files plus 3,081 raw files; all 13 required routes; 2,969 final HTML files / 5,864 routes / 283,184 hrefs; 6,045 unique generated internal URLs; and `git diff --check`.

### Known Notes

- The provenance audit remains read-only and advisory; this release adds neither automatic marker insertion nor a hard release gate.
- The 2,280 residuals are not a declaration that 2,280 claims are wrong. They are a bounded queue requiring human review of public-source scope.
- Non-table low-marker batches #221-#224 and the human governance decision in #193 remain separate scopes.

### Next Steps

- Pass canonical verification on the source commit, both `pre` / `main` PR checks, and production deployment.
- Create tag/GitHub Release `v2026.07.29-5` on the same main merge SHA as production.
- Close Issue #219 with the exact mapping, detector contract, 14 child routes, and passing gates; update parent #192; then begin public-source content review with batch #231.
