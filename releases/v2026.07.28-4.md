# 活用中の開発文書とリポジトリ情報の修復

## 日本語

### 公開範囲

- Issue #189 の active developer docs、root `INDEX.md`、三言語 `README.md`、package license metadata、stale-doc audit tooling、CHANGELOG、release note、および release generator が同期する公開 discovery surface。
- wiki entry の事実本文、`site/src/content/i18n/{ja,en}/**`、domain map の内容と件数は変更しない。

### 主要変更

- backlog、roadmap、next-development-plan、Astro upgrade plan、architecture / quality audit を更新し、完了済み issue を future / open blocker として扱わないようにした。GitHub Issues を live scope、state、dependency、ordering の唯一の真相源とした。
- active docs と root `INDEX.md` から揮発しやすい corpus / entry / domain snapshot を除き、`ai-index.json`、root Domain Map、strict release、wikilink audit、`index:counts` を current metric source とした。
- filesystem mtime 復元の旧手順を、full Git history、committed discovery fallback、source commit 後の release generation、mtime terminal fallback という現行 contract に置き換えた。
- `package.json` の license を repository の Apache 2.0 license text と一致させた。
- `docs:stale` を testable API にし、番号付き current issue queue、実装済み plan の future 表現、生成 metric drift、obsolete mtime guidance、package / LICENSE mismatch を検出する focused fixtures を追加した。

### 検証結果

- `bun test tools/active_doc_stale_scan.test.ts` は 3 tests / 3 assertions で通過した。
- `bun run docs:stale` は 66 active docs / 16 checks、`bun run docs:audit`、`bun run index:counts` は drift 0、`git diff --check` はすべて通過した。
- `bun run verify --out _site` は 53 tests / 177 assertions、Astro check 39 files / 0 errors / 0 warnings / 5 hints、Astro 2,969 pages、duplicate ID 0、Pagefind 2,968 pages、assembly 6,258 Astro files + 3,065 raw files、13 required routes、6,029 unique internal URLs、production dependency vulnerability 0 で通過した。
