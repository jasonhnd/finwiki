- 内訳は asset-managers 20 warnings / 13 paths、financial-conglomerates 8 / 7、manufacturer-finance 23 / 11、megabanks 34 / 19、trading-company-finance 28 / 7、trust-banks 55 / 32。

### 主要変更

- 同一 source set が table 全体を支える場合だけ scoped footer marker を追加し、row ごとに根拠が異なる表では row-level marker / direct public link を保持した。遠い `## Sources` や generic marker を table coverage とみなしていない。
- asset manager では、金融庁の現行登録、公式 company profile、商品・運用開示に合わせて法人名、登録業務、所在地、グループ境界、開示済み運用規模を校正した。Principal Japan は未特定法人や保険免許を推定せず、プリンシパル・グローバル・インベスターズ株式会社の確認済み金融商品取引業へ境界を固定した。
- financial conglomerate / trading-company finance / manufacturer finance では、連結 group と個別法人、商社本体の財務機能と別法人の金融商品、製造業の captive / vendor / export finance を分離した。未開示の融資規模、系列関係、商品 availability、優位性を確定事実から除き、公式組織・事業・開示資料が立証する範囲に限定した。
- megabank / trust-bank では、現行法人・持株会社・ブランド、登録・免許、所有関係、合併・商号変更、開示期を再確認した。金融庁の 2026-06-30 一覧にもとづき信託会社は合計 37 社（運用型 13、管理型 24）へ更新し、Mitra の現商号、Northern Trust Japan の法人区分、Sumitomo Mitsui Trust の FY2025 開示を各公式資料へ揃えた。
- 89 source entries の `last_updated` / `last_tended` を 2026-07-29、`review_by` を 2026-10-27 に更新した。ja / en 178 mirrors は table、marker、隣接見出し、`source_hash`、`translated_at` を同期し、翻訳保護に不合格の候補は正式 mirror へ反映していない。

- `bun run wiki:audit:ci` は 1,489 entries、link issues 0、canonical drift 0。`bun run i18n:check` は ja / en 各 1,442 mirrors が全件 current、stale / orphaned / missing 0、`fidelity: ok` 各 1,442 となった。

### 既知の注意点

- provenance audit は read-only / advisory であり、168 warnings の解消は corpus 全体または各 entry の全 prose を一括保証しない。今回の実証範囲は owned table / row と直近 evidence context である。
