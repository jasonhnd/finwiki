# 表出典168件と金融グループ事実の校正

## 日本語

### 公開範囲

- Issue #232 の current released-main snapshot にある `table_without_provenance` / `table_row_without_marker` 168 件、89 source paths を bounded scope とする。
- 内訳は asset-managers 20 warnings / 13 paths、financial-conglomerates 8 / 7、manufacturer-finance 23 / 11、megabanks 34 / 19、trading-company-finance 28 / 7、trust-banks 55 / 32。
- 公開一次資料、金融庁 registry、issuer disclosure、公式会社概要・沿革・業務資料を用い、table 本体と直近の evidence context を再検証する。
- 89 source entries、ja / en 178 mirrors、三言語 release / operating surfaces、root index / discovery surfaces を同じ release unit で同期する。
- `.opinions/**`、`docs/**`、人手判断を待つ Issue #193、後続 Issue #233–#244 の所有範囲は変更しない。

### 主要変更

- 同一 source set が table 全体を支える場合だけ scoped footer marker を追加し、row ごとに根拠が異なる表では row-level marker / direct public link を保持した。遠い `## Sources` や generic marker を table coverage とみなしていない。
- asset manager では、金融庁の現行登録、公式 company profile、商品・運用開示に合わせて法人名、登録業務、所在地、グループ境界、開示済み運用規模を校正した。Principal Japan は未特定法人や保険免許を推定せず、プリンシパル・グローバル・インベスターズ株式会社の確認済み金融商品取引業へ境界を固定した。
- financial conglomerate / trading-company finance / manufacturer finance では、連結 group と個別法人、商社本体の財務機能と別法人の金融商品、製造業の captive / vendor / export finance を分離した。未開示の融資規模、系列関係、商品 availability、優位性を確定事実から除き、公式組織・事業・開示資料が立証する範囲に限定した。
- megabank / trust-bank では、現行法人・持株会社・ブランド、登録・免許、所有関係、合併・商号変更、開示期を再確認した。金融庁の 2026-06-30 一覧にもとづき信託会社は合計 37 社（運用型 13、管理型 24）へ更新し、Mitra の現商号、Northern Trust Japan の法人区分、Sumitomo Mitsui Trust の FY2025 開示を各公式資料へ揃えた。
- 89 source entries の `last_updated` / `last_tended` を 2026-07-29、`review_by` を 2026-10-27 に更新した。ja / en 178 mirrors は table、marker、隣接見出し、`source_hash`、`translated_at` を同期し、翻訳保護に不合格の候補は正式 mirror へ反映していない。

### 検証結果

- `bun run provenance:audit -- --json` は full warnings を 2,151 から 1,983 へ削減し、Issue #232 の owned warnings を 168 から 0 にした。6 domain すべてで owned residual 0 を確認し、full residual は `table_without_provenance` 1,894 と `table_row_without_marker` 89 である。
- `bun run audit:all -- --as-of 2026-07-29` は factual-consistency conflict 0、cross-path needs-review pattern 0、provenance needs-review threshold 0、Tier-1 review-by due 0。queue-growth monitor 1 は advisory のままである。
- `bun run wiki:audit:ci` は 1,489 entries、link issues 0、canonical drift 0。`bun run i18n:check` は ja / en 各 1,442 mirrors が全件 current、stale / orphaned / missing 0、`fidelity: ok` 各 1,442 となった。
- `bun run release:write` は release docs 30 files / 28 current notes、Markdown 1,601、40 domains、1,489 link-audited entries、11,027,888 non-space chars、1,776,277 word-like tokens を同期し、AI discovery を 1,600 public pages / 1,482 sitemap・API entries へ再生成した。full canonical `bun run verify --out _site` は Bun 1.3.14、production dependency vulnerabilities 0、Astro diagnostics 0、98 / 98 tests、2,969 built pages、2,968 Pagefind pages、duplicate HTML IDs 0、entry metadata issues 0、285,062 hrefs / 5,864 routes、6,051 generated internal URLs、`git diff --check` をすべて PASS した。

### 既知の注意点

- provenance audit は read-only / advisory であり、168 warnings の解消は corpus 全体または各 entry の全 prose を一括保証しない。今回の実証範囲は owned table / row と直近 evidence context である。
- corpus 全体には 1,983 件の table-related residual warnings が残り、後続の bounded issues が所有する。件数だけを減らすための marker 挿入は行わない。
- registry、会社名、所有関係、AUM、product availability、財務数値、組織再編は変動するため、公式資料の再確認と 90-day review cadence を維持する。
