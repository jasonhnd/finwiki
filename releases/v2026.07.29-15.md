# デリバティブ・証券化の表出典196件を校正

## 日本語

### 公開範囲

- Issue #236 の released-main `dd1d69bd` baseline にある 196 `table_without_provenance` warnings / 54 source paths を bounded scope とする。
- 内訳は `derivatives/` 123 warnings / 31 paths、`structured-finance/` 73 / 23 である。
- 54 source entries、対応する ja / en 108 mirrors、三言語 release / operating surfaces、root index / AI discovery surfaces を同じ release unit で同期する。
- `.opinions/**`、`docs/**`、人手判断を待つ Issue #193、後続 Issue #237–#244、両 domain 内の非 owned paths は変更しない。

### 主要変更

- JPX、BOJ、FSA、ISDA、JHF、法令、issuer / rating material を table scope ごとに結び、generic homepage や frontmatter source inventory だけで contract specification、market scale、法的・税務結果を cover しない形へ修正した。
- ISDA 2020 protocol の対象 benchmark と cessation trigger を分離し、JPY TIBOR / Euroyen TIBOR、JPY LIBOR、TONA / CAS の状態を公式 protocol material に合わせた。
- JPX の current futures / options specification と FSA の個人・法人 FX margin / loss-cut rule を校正し、古い underlying 数、trading hour、contract unit、固定 leverage / loss-protection 表現を撤回した。
- JHF MBS を senior / subordinated tranche + guarantee とみなす説明を、JHF 自身の元利金適時支払義務、第三者受益信託と受益権行使事由、事由発生後の信託受益権に対する通常の月次 MBS の OC、Green MBS の非 OC という current official structure へ修正した。
- TMK、GK-TK、信託受益権、covered bond、rating / waterfall / spread / issuance volume は法的 vehicle、税務条件、deal / vintage を区別し、裏付けのない一般値・順位・市場慣行を確定事実から除いた。
- ja / en mirrors では、benchmark 名、contract term、日付、bp / 金額 / 比率、法律用語、否定・条件表現、URL、wikilink、table / list shape を source correction と同じ意味へ同期した。

### 検証結果

- baseline `bun run provenance:audit -- --json` は full 1,591 warnings、Issue #236 owned 196 / 54 paths を再現した。校正後は full 1,395 = 1,328 `table_without_provenance` + 67 `table_row_without_marker`、Issue #236 owned 0 / 0 paths となった。
- 54 / 54 source の independent mirror QA を通過し、108 mirrors は semantic / structural parity を維持した。`i18n:check` は ja / en 各 1,442 current、stale / orphaned / missing 0、`fidelity: ok` 各 1,442。`audit:all --as-of 2026-07-29` は blocking 0（queue monitor 1 は advisory）、`wiki:audit:ci` は 1,489 entries / issues 0 / dead links 0 / canonical drift 0、release docs は 34 files / strict 32 / problems 0 だった。
- `release:write` は Markdown 1,605 / 40 domains / 1,489 entries と 1,604 public pages / 1,482 sitemap・API entries を同期した。full `bun run verify --out _site` は Bun 1.3.14、dependency vulnerabilities 0、Astro diagnostics 0、98 / 98 tests・327 assertions、2,969 built pages、2,968 Pagefind pages、HTML 2,969 / hrefs 283,693 / routes 5,864、generated URLs 6,055、`git diff --check` を PASS した。
- real pre-push hook でも同じ canonical verification を `_vercel_public` に対して再実行し、required routes 13、HTML route audit、generated URL audit、patch whitespace を含めて PASS した。

### 既知の注意点

- provenance audit は read-only / advisory であり、196 warnings の解消は corpus 全体または各 entry の全 prose を一括保証しない。実証範囲は owned tables / rows と修正に必要な直近 context である。
- exchange specification、benchmark status、margin rule、rating、spread、issuance、tax treatment は日付、契約、deal、法的事実により変動する。基準日と適用範囲を保ち、一般化しない。
- rating-agency / issuer material の一部は動的 route または automated-request restriction があるため、bot policy と dead URL を区別し、公開される具体的資料だけを evidence とする。
