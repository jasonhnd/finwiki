# 低密度出典17件と翻訳保護の校正

## 日本語

### 公開範囲

- Issue #221 が所有する 17 件の `low_marker_density` warning を、15 件の公開 wiki entry と対応する ja / en 30 mirrors で再検証する。
- Issue #247 で URL-bearing provenance marker の translation mask / unmask losslessness を修復する。
- FSA、FCA、SEC、JVCEA、企業公式開示・公式 product page を優先し、近接 provenance marker、数字、日付、法人・ライセンス区分を同期する。
- `.opinions/**`、`docs/**`、別 Issue が所有する残余 provenance queue は変更しない。

### 主要変更

- Privy は 2025-06-11 の公式発表で確認できる 75M+ accounts / 1,000+ developer teams を採用し、未開示の買収価格、110M wallets、推定 valuation を確定事実から除外した。
- FSA workbook を 2026-07-29 に再確認し、外国銀行支店 57、暗号資産交換業者 26、電子決済手段等取引業者 1、金融商品取引業者 1,954 を明示した。電子決済手段の trust route は trust bank だけに限定されず、現行の取扱欄は USDC / RLUSD / JPYSC を掲げる。
- Laser Digital Japan の JVCEA 第二種会員を第二種金融商品取引業登録と混同しないよう修正した。Crypto Garage は Digital Garage + Tokyo Tanshi の joint venture、暗号資産交換業 No. 00029 とし、根拠のない Daiwa parent / in-group bank route を除外した。
- bitFlyer の旧 private cap-table 推計、Sony FG の出典未確認 opening price、BlackRock / BTC ETP の未立証 AUM・因果、CBJ の custody majority / merger-accounting 推計を、一次資料で確認できる範囲へ限定した。
- DMM.com Securities と DMM Bitcoin の法人・登録を分離し、S.BLOX の company rename と service rename を別 event として整理した。UK FCA は current MLR registration と 2027-10-25 開始の新 FSMA regime を区別した。
- 15 source entries の `last_updated` / `last_tended` を 2026-07-29、`review_by` を 2026-10-27 に揃え、ja / en mirrors と source hashes を同期した。
- complete `^[...]` marker を URL・日付・数字より先に原子的に mask するよう変更し、marker 内の URL が nested placeholder になる問題を解消した。

### 検証結果

- `bun run provenance:audit -- --json` は full warning を 2,336 から 2,319、`low_marker_density` を 56 から 39 へ削減し、Issue #221 の 17 件は 0、`needs_review=0` となった。table-related residuals 2,280 は不変である。
- `bun run audit:all -- --as-of 2026-07-29` は factual consistency、provenance needs-review、Tier-1 freshness の blocking count 0 で完走した。
- `bun run wiki:audit:ci` は 1,489 entries、link issues 0、canonical drift 0。`bun run i18n:status -- --json` は ja / en 各 1,442 mirrors が全件 current で、stale / orphaned / missing / source-pointer drift 0、`fidelity: ok` 各 1,442 となった。
- focused translation-protection suite は 13 tests / 51 assertions で PASS し、single / multiple URL marker と 5 sample source files の lossless round trip を確認した。
- `bun run release:write` は 1,596 Markdown / 1,595 public pages / 1,489 entries / 1,482 API entries を同期した。full canonical `bun run verify --out _site` は release docs 25 files / 23 strict notes / problems 0、generated-surface leakage 0、production vulnerabilities 0、Astro check 44 files / 0 errors / 0 warnings / 0 hints、98 tests / 327 assertions、Astro 2,969 pages、entry metadata 2,884 pages / issues 0、Pagefind 2,968 pages、assembly 6,258 Astro + 3,082 raw files、13 required routes、final HTML 2,969 files / 5,864 routes / 283,248 hrefs、generated URLs 6,046、`git diff --check` をすべて PASS した。PR checks と production deployment は promotion 段階で記録する。

### 既知の注意点

- provenance audit は read-only / advisory であり、warning の減少は corpus 全体の事実が一括保証されたことを意味しない。
- FSA / FCA registry、取扱 instrument、企業所有・ライセンス情報は変わり得るため、`review_by` cadence と公式一次資料による再確認を維持する。
- 残る 39 件の non-table low-marker warnings と 2,280 件の table-related residuals は、それぞれ別の bounded Issues が所有する。

### 次の作業

- `bun run release:write` と full `bun run verify --out _site`、real pre-push hook、`pre` / `main` PR checks を通す。
- production deployment と同じ main merge SHA に tag / GitHub Release `v2026.07.29-6` を作成する。
- Issue #221 / #247 に exact audit delta、official-source decisions、translation / deployment / release evidence を記録して close し、親 Issue #192 を更新して #222 を開始する。
