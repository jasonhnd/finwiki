## English

### Release Scope

- Issue #194 entry review-overdue display, a shared JST date helper, focused boundary tests for yesterday/today/tomorrow/missing values, and the trilingual CHANGELOG/release note.
- Factual wiki-entry bodies, frontmatter, and `ja` / `en` translation mirrors are unchanged.

### Major Changes

- Removed the embedded `2026-06-02` comparison from `EntryLayout.astro` and use the `Asia/Tokyo` calendar date of each static build.
- Apply the warning state only when `review_by` is before today. Today and future dates are not warnings, and missing or invalid values are not treated as overdue.
- Locked the UTC 14:59:59 to 15:00:00 JST calendar rollover and the yesterday/today/tomorrow boundaries with pure-helper unit tests.

### Validation Results

- Focused review-date suite: 4 tests / 10 assertions passed.
- Full canonical `bun run verify --out _site`: passed with 54 tests / 184 assertions, Astro check across 40 files with 0 errors / 0 warnings / 5 known hints, 2,969 Astro pages, zero duplicate HTML IDs, 2,968 Pagefind pages, 13 required routes, 6,029 generated internal URLs, and zero production vulnerabilities.
- `git diff --check` passed.

### Known Notes

- The overdue state is calculated from the static build's JST date. It updates on every rebuild instead of using a hard-coded date, while an already deployed artifact remains unchanged until the next build.
- The five Astro hints remain the existing Issue #198 scope.
