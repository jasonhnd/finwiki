# レビュー期限の日本標準時日付判定修復

## 日本語

### 公開範囲

- Issue #194 の entry review overdue 表示、shared JST date helper、昨日 / 今日 / 明日 / 欠落値の focused boundary tests、三言語 CHANGELOG / release note。
- wiki entry の事実本文、frontmatter、`ja` / `en` translation mirror は変更しません。

### 主要変更

- `EntryLayout.astro` に埋め込まれていた `2026-06-02` の比較基準を削除し、各 static build 時点の `Asia/Tokyo` calendar date を使用します。
- `review_by` が今日より前の場合だけ warning state とし、今日と将来日は warning にせず、欠落値または不正値も overdue として扱いません。
- UTC 14:59:59 から 15:00:00 への JST calendar rollover と、昨日 / 今日 / 明日の境界を pure helper の unit tests で固定しました。

### 検証結果

- focused review-date suite: 4 tests / 10 assertions PASS。
- full canonical `bun run verify --out _site`: 54 tests / 184 assertions、Astro check 40 files / 0 errors / 0 warnings / 5 既知 hints、Astro 2,969 pages、duplicate HTML id 0、Pagefind 2,968 pages、13 required routes、6,029 generated internal URLs、production vulnerabilities 0 で PASS。
- `git diff --check` PASS。

### 既知の注意点

- overdue state は static build の JST 日付で計算されます。hard-coded date ではなく再 build ごとに更新されますが、既に deploy 済みの artifact 自体は次の build まで変化しません。
- 5 Astro hints は Issue #198 の既存 scope です。

### 次の作業

- real pre-push を通して `pre` 向け PR を作成し、CI / preview deployment の evidence を Issue #194 に記録します。
- `main` promotion と GitHub Release は承認済み release flow でのみ行います。

## English

### Release Scope
