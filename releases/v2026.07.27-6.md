# 発見経路と公開先契約の修復

## 日本語

### 公開範囲

- Issue #179 の shared Markdown route resolution、AI discovery generator、API `external_links` normalization、最終 assembled artifact の route audit、generated-surface drift scan、output comparator、canonical verification wiring、`.github/workflows/deploy.yml` と `.github/workflows/required-verification.yml` の full-history checkout、focused tests、三言語 README / CHANGELOG / release note。
- wiki entry の事実本文、`ja` / `en` mirror 本文、domain map は変更しません。

### 主要変更

- 日本語 HTML canonical を `/ja/{route}/`、英語 alternate を `/en/{route}/`、公開 raw Markdown を明示的な `.md` URL として解決し、static artifact に公開できない source は GitHub URL へ fallback する shared contract を導入しました。
- sitemap、API、AI index が source path ではなく実際に deploy される URL を出力し、API `external_links` は absolute HTTP(S) だけを保持するよう統一しました。最終 assembled output の全 declared internal route URL を監査し、wrong-origin は fail closed とします。
- 更新日は従来どおり git history を第一 source とし、workflow は full history を取得します。shallow / history-less builder では committed discovery date、最後に mtime を使用します。exact drift gate は committed generated surface と、その fixed timestamp による一回の clean regeneration を `last_modified` まで byte 単位で比較します。
- Git query と shallow-clone fixture は inherited `GIT_*` repository context を除去し、fixture cleanup は suite 完了時に行うため、pre-push と並行 test のどちらでも別 repository を参照・削除しません。

### 検証結果

- focused suite は 24 tests / 102 assertions PASS。
- `bun run verify --out _site` の full canonical gate は 50 tests / 174 assertions、Astro check 39 files / 0 errors / 0 warnings / 5 hints、Astro 2,969 pages、duplicate ID 0、Pagefind 2,968 pages、assembly 6,258 Astro files + 3,064 raw files、13 required routes で PASS。
- assembled route audit は 6,028 unique internal URLs を確認して PASS し、generated-surface drift scan は committed surface と一回の fixed-timestamp clean regeneration が `last_modified` を含め byte-identical であることを確認しました。strict release check も PASS。
- release-inclusive snapshot は Markdown 1,578、public pages 1,577、sitemap URLs 1,482、domains 40、audited entries 1,489、10,613,259 non-space characters、約 1,703,143 word-like tokens です。

### 既知の注意点

- release generator、README / index / discovery surface の同期、full canonical gate は完了しています。
- commit、push、remote verification、PR / CI、Vercel deployment、GitHub Release はまだ実施・確認していません。

### 次の作業

- source commit 後に discovery date を再生成して amend に含めます。
- push、remote HEAD、CI / deployment status を確認して Issue #179 に最終 evidence を記録します。`main` publish と GitHub Release は dependency review 後の承認済み promotion 時に行います。

- Introduced a shared contract resolving Japanese HTML canonicals to `/ja/{route}/`, English alternates to `/en/{route}/`, and published raw Markdown to explicit `.md` URLs, with GitHub fallback for sources that cannot enter the static artifact.
- Aligned sitemap, API, and AI indexes to emit actually deployed URLs rather than source-derived paths, and normalized API `external_links` to absolute HTTP(S). Every declared internal route URL is audited against the final assembled output, with a wrong origin failing closed.
