# 依存関係と監査ゲートの更新

## 日本語

### 公開範囲

- Issue #186 の Astro / Satteri 依存関係、Bun lockfile、production dependency audit、GitHub Pages / Vercel build pipeline、三言語 README / CHANGELOG / release note と生成 public snapshot。
- Bun runtime の固定は Issue #184、TypeScript / typecheck の更新は Issue #185 の別 scope です。

### 主要変更

- `astro` を 7.1.3、`@astrojs/markdown-satteri` を 0.3.4、`satteri` を 0.9.5 へ更新し、lockfile を安全な transitive dependency へ再解決しました。
- site install を `--frozen-lockfile` に変更し、Pages / Vercel build と pull request、`pre` / `main` push、週次 schedule で `bun audit --production` を実行します。
- root に `bun run dependency:audit` を追加し、同じ監査をローカルでも再現可能にしました。

### 検証結果

- `bun audit --production` は production vulnerability 0 件、`bun install --frozen-lockfile --ignore-scripts` は lockfile 変更なしで完了しました。
- `bun tools/vercel_build.ts` は link audit、strict release check、dependency audit、publish tests 7/7、Astro build（2,969 pages）、duplicate ID check（0）、Pagefind（2,968 pages）と assembly（Astro 6,258 files + raw 3,060 files）を通過しました。
- release-document、docs、generated-surface、txt-route、i18n、index-count、wiki-link、workflow YAML と diff gate も PASS しました。

### 既知の注意点

- audit workflow の `bun-version: latest` は Issue #184 が repository-wide pin を導入するまで維持します。
- #186 branch は PR #197 の commit に積み重ねているため、PR #197 が `pre` へ merge されるまで重複 PR を開きません。

### 次の作業

- PR #197 merge 後に最新 `pre` へ重ね直し、#186 PR を開いて review / CI を待ちます。self-merge / self-close は行いません。
