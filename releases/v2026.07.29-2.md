# 事実鮮度イベント推論の精度改善

## 日本語

### 公開範囲

- Issue #217 の fact-freshness event inference と frontmatter / body context boundary を修復する。
- 対象は read-only audit tool、focused tests、active architecture contract、三言語 README / CHANGELOG / release state と generated discovery surfaces。
- wiki facts、source entry metadata、ja / en translation bodies、hard release gate は変更しない。

### 主要変更

- 45-day `event` class を route / title に明示された lifecycle-state cue に限定した。本文での背景言及や topical tag は active event を意味しない。
- transaction / bankruptcy / migration topic は `volatile_topic_keyword`、case study は `case_study_keyword` として最大 90-day `high` に留めた。
- body context から frontmatter を除外し、`status:` field name 自体が registry / status keyword に一致する false positive を防いだ。
- generic use case、true deadline event、historical case study、transaction mechanism、registry、future review date を focused regression fixture で固定した。

### 検証結果

- focused suite は 1 test / 13 assertions、全 repository suite は 87 tests / 307 assertions で PASS。
- `docs:audit` と `docs:stale` は 67 active docs / 16 checks で PASS。
- exact 2026-07-29 truthfulness audit の actionable freshness は 458 から 3 に減少し、455 `cadence_due,event_keyword` rows は detector false positives として解消した。
- 残る 3 rows はすべて `candidate_status` で Issue #220 に割り当て済み。consistency / provenance queues は非表示化せず別 child issues の ownership を維持した。
- full canonical `bun run verify --out _site` は release docs 21 files / 19 strict notes / 76 grandfathered notes、wiki 1,489 entries / issues 0 / canonical drift 0、generated API 1,482 entries / byte identity / leakage 0、ja / en 各 1,442 current mirrors、production vulnerability 0、Astro check 44 files / 0 errors / 0 warnings / 0 hints、87 tests / 307 assertions、Astro 2,969 pages、entry metadata 2,884 / issues 0、Pagefind 2,968 pages、13 required routes、final HTML 5,864 routes、generated URL 6,042 unique internal URLs、`git diff --check` を含めて PASS。

### 既知の注意点

- report は advisory であり、public facts の currentness を自動証明しない。
- explicit lifecycle state、candidate / borderline status、missing / due `review_by` と弱い source inventory は引き続き actionable である。
- Issue #193 の `.opinions/**` public boundary は別の human decision のままである。

### 次の作業

- current source commit で real pre-push と PR Required Verification / Dependency Audit / Vercel を通す。
- verified `pre` merge を approved promotion で `main` へ反映し、production deploy 後に同じ main merge SHA へ tag / GitHub Release `v2026.07.29-2` を作成する。
- Issue #220 で残る 3 candidate entries を official public sources により recheck し、#218 / #219 / #221-#224 の bounded queues を継続する。

## English

### Release Scope

- Repair fact-freshness event inference and the frontmatter/body context boundary tracked by Issue #217.
- Scope covers the read-only audit tool, focused tests, the active architecture contract, trilingual README/CHANGELOG/release state, and generated discovery surfaces.

- Removed frontmatter from body context so the `status:` field name itself cannot trigger a registry/status false positive.
