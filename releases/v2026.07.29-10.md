- 一つの source set が table 全体を支える場合は scoped footer marker を追加し、row ごとに根拠が異なる場合は row-level marker / direct public link を保持した。遠い `## Sources` や generic marker を table coverage とみなしていない。

- 73 source entries の `last_updated` / `last_tended` を 2026-07-29、`review_by` を 2026-10-27 に更新した。ja / en 146 mirrors は table、scoped marker、隣接見出し、`source_hash`、`translated_at` を同期した。
